# BestStock 投资 Skill 项目

BestStock 是一个面向价值投资研究的投资 skill 项目。项目目标是把经典投资大师留下的原始资料凝练成一套尽可能完备、可执行、可复用的投资分析 skill；生成过程主要使用 GPT-5.5 xhigh 模式，并少量使用 Claude Sonnet 4.6 Adaptive 模式。

这个项目并不试图让模型替代人的判断，而是希望形成一个“以人为主、筛选为辅”的投资系统：先借助公开股票接口数据、年报数据和大师方法论快速筛查值得关注的公司集合，再用 skill 从大师视角深入选拔真正值得研究、值得长期跟踪、可能值得投资的公司。

## 项目愿景

本项目希望同时服务两个目标：

1. 快速筛选公司：通过公开股票数据、财务数据、年报材料和结构化分析框架，从大量公司中筛出值得进一步关注的候选集合。
2. 深度提升判断力：通过阅读和使用由大师原始资料凝练出的 skill，帮助使用者系统掌握价值投资理念，训练自己的商业判断、风险意识、估值纪律和长期主义思维。

最终形成的系统应当是一个投资研究助手，而不是投资决策机器。它负责扩大视野、提高效率、提供结构化问题、发现风险盲点；最终判断仍由人完成。

## 当前进展

原始资料收集阶段已经完成。项目目前正在进行第一批初版 skill 的生产，这一阶段主要由 GPT-5.5 xhigh 驱动，并少量使用 Claude Sonnet 4.6 Adaptive，用于从已整理的原始资料中提炼初步方法论。每一批精读页面的请求范围保持在 35 页左右，以保证输出质量。由于生成过程主要使用 GPT-5.5 xhigh 模式，并少量使用 Claude Sonnet 4.6 Adaptive 模式，因此少量文档名称和格式略有不同。

## 核心思想

项目的核心方法是：先完整阅读，再压缩为方法论。

为了让生成过程中主要使用的 GPT-5.5 xhigh 和少量使用的 Claude Sonnet 4.6 Adaptive 尽可能精确地理解原始资料，本项目将书籍、股东信、股东大会文字记录、基金信函和投资备忘录等资料拆分为较小批次。多数资料按约 35 页一组切分，部分资料会按照原始结构、页数或会议分场进行切分，例如年度股东信、伯克希尔股东大会上下午场、少量 25 页分组等。

每个批次的处理原则是：

1. 要求模型完整阅读原始资料，而不是只做局部摘要。
2. 要求模型在完整理解后，再压缩成可执行的方法论。
3. 要求输出中文 skill，保留大师思想的关键判断标准、问题清单、反例、适用边界和风险提醒。
4. 第一轮先从每一批资料中提炼局部 skill。
5. 第二轮再将多个局部 skill 合并，通过求同存异形成更高质量的综合 skill。
6. 最终根据需要形成一个总 skill，或按主题、资料来源、分析环节拆成多个 skill。

## 预期能力

完成后的投资 skill 预计覆盖以下能力：

- 公司初筛：用公开股票接口数据筛选出基本面、估值、盈利质量、资产质量、资本回报等方面值得关注的公司。
- 年报阅读：从商业模式、竞争优势、财务质量、管理层行为、资本配置、风险披露等角度阅读年报。
- 大师视角分析：综合格雷厄姆、巴菲特、芒格、费雪、彼得·林奇、格林布拉特、霍华德·马克斯、塞思·卡拉曼、尼克·斯利普等人的思想框架。
- 风险识别：识别财务杠杆、周期性、管理层激励、估值过高、会计质量、行业变化、竞争格局恶化等风险。
- 估值与安全边际：围绕保守假设、长期现金流、再投资能力、资本回报率和市场情绪建立估值纪律。
- 投资备忘录：输出结构化研究结论，明确看好理由、反对理由、关键变量、跟踪指标和买入前提。

## 工作流

当前项目可以按照以下流程推进：

1. 整理原始资料  
   将经典投资资料放入 `origindata/`，并按资料来源、作者、书名或年份组织目录。

2. 分块阅读与初步凝练  
   对每个分块使用强调“完整阅读后再压缩”的提示词，让模型先充分理解原文，再输出该分块对应的分析方法、判断标准和思想精华。

3. 生成局部 skill  
   按书籍、股东信、会议记录、备忘录或基金信函分别形成局部 skill，保留每类资料的独特视角。

4. 合并多个 skill  
   将多个局部 skill 求同存异，合并重复原则，保留差异化洞见，删除空泛表述，形成更高密度的综合投资 skill。

5. 应用到公司研究  
   将公开股票接口数据和年报数据输入 skill，先做批量筛查，再对候选公司进行深度研究。

6. 人类复核与决策  
   人负责最终判断，包括理解商业本质、识别模型遗漏、检查事实来源、确认估值假设和承担投资责任。

## origindata 内容说明

`origindata/` 是本项目最重要的原始资料目录。当前目录共包含 397 个文件，其中包括 222 个 PDF、149 个 Markdown 文件和 26 个 TXT 文件。

该目录中的内容主要分为以下几类：

1. 价值投资经典书籍  
   包括《证券分析》《聪明的投资者》《安全边际》《穷查理宝典》《怎样选择成长股》《彼得·林奇的成功投资》《战胜华尔街》《股市稳赚》《股市天才》《利息理论》等。这些资料大多已经按页码范围拆分，例如 `001-035.pdf`、`036-070.pdf`。

2. 巴菲特与伯克希尔资料  
   包括 `巴菲特股东信全集-伯克希尔官网(Berkshire Hathaway Shareholder Letters - Official Berkshire Website)/`、`伯克希尔股东大会全集-巴菲特、芒格(Berkshire Annual Meeting Transcripts - Buffett and Munger)/`，以及巴菲特和查理·芒格 2014 年关于过去、现在和未来的特别来信。股东信资料覆盖早期合并文件和 1970 年代至 2024 年的年度材料；股东大会资料按年份和上下午场切分，便于逐批阅读和提炼。

3. 现代价值投资与周期思想资料  
   包括 `橡树资本备忘录全集-霍华德·马克斯(Oaktree Capital Memos - Howard Marks)/`、`游牧人基金信函全集-尼克·斯利普、凯伊斯·扎卡里亚(Nomad Investment Partnership Letters - Nick Sleep and Qais Zakaria)/` 等。这类资料适合提炼风险控制、周期判断、长期持有、商业质量和逆向投资方面的框架。

4. Prompt 模板  
   `_AIPrompt模板.txt` 记录了项目用于生成 skill 的提示词思路，核心要求是根据引用文件完整分析原文，凝练出分析公司的方式和思想精华，并在完整阅读后再压缩成方法论。

这些资料是后续生成投资 skill 的输入基础。后续新增资料时，建议继续保持“按来源归档、按页码或结构分块、文件名清晰可追踪”的组织方式，方便模型引用、复核和合并。

## 使用建议

生成 skill 时，建议每一轮都明确说明：

- 引用哪些原始文件。
- 要求完整阅读后再压缩。
- 输出应是可执行的方法论，而不是普通读书摘要。
- 保留原作者独特观点，也要标注适用条件和局限。
- 合并 skill 时要去重、求同存异，并保留关键反例和风险清单。

用于公司研究时，建议采用两阶段流程：

1. 批量筛查阶段：用数据接口先筛出值得研究的公司集合。
2. 深度研究阶段：用综合 skill 阅读年报、分析商业模式、评估估值和风险，最终形成投资备忘录。

## 注意事项

本项目用于投资研究、学习和方法论构建，不构成任何投资建议。股票投资存在本金损失风险，任何模型输出都必须经过事实核查、人类复核和独立判断。

原始资料可能涉及版权内容，请仅在合法授权、个人学习或研究范围内使用，并在传播、训练、发布或商业化使用前确认相关版权要求。
