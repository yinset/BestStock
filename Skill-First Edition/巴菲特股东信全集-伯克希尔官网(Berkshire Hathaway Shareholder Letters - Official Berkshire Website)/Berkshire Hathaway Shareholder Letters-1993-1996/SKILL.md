# 巴菲特公司分析 1993-1996

## 核心姿态

把公司当作长期所有权来分析，把买入整家公司、买入一部分上市股权、回购、发股、分红、持有现金和承保保险风险都放进同一张机会成本表。目标不是 EPS 增厚、短期报价、规模扩张、平滑利润或宏观预测，而是每股内在价值在长期内以可理解、可持续、股东可获得的方式增长。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 先界定所有者问题
   - 说明分析对象是上市股权、控股收购、家族企业出售、保险业务、银行/金融业务、控股公司，还是混合型公司。
   - 把问题改写为：以当前价格买入这份长期所有权，未来税后、通胀后、风险调整后的购买力是否会增加。
   - 不从宏观预测、行业愿景或战略规划出发。先问这家公司是否落在能力圈和“好球区”内；若不在，直接放弃。
   - 对任何资本动作，都和可买到的其他优秀企业、现金、债券、回购、分红、还债和不行动比较。

2. 估算内在价值，而不是迷信账面价值
   - 把内在价值定义为企业余生可取出的现金按合适利率折现后的现值。承认它主观、模糊，但它是唯一合乎逻辑的价值尺度。
   - 把账面价值视为历史投入或粗略跟踪器，不把它等同于商业价值。优秀业务可能在账面上被低估，糟糕资产也可能账面高于真实价值。
   - 对控股公司或混合型公司，用两个指标拆分价值：每股投资资产（含现金和可交易证券）与每股经营业务税前收益（排除投资收益、资本利得、采购会计调整，扣除总部费用和利息）。
   - 分析发股、收购和融资时，始终问每股内在价值是否增加。只有收到的内在价值至少等于交出的内在价值，发行股票才合理。
   - 区分业务表现和股票表现。股价短期跑赢业务会提前透支，股价短期落后业务会改善价格/价值关系。

3. 还原 look-through earnings
   - 从报告经营收益出发，加上重大参股公司未分配经营收益中属于自己的份额，再扣除如果这些收益以股息形式分回时应缴的假设税。
   - 排除资本利得、采购会计摊销、重大一次性项目和会计规则变化；它们可以影响报表，却不一定反映经营进步。
   - 若被投资公司能以高回报再投资，留存收益通常比派息更有价值。不要因为留存收益没进入本期利润表就忽略它。
   - 用 5 年、10 年、20 年的穿透收益增长验证投资组合价值；长期股价最终必须由穿透收益支持。

4. 判断业务质量和护城河
   - 优先寻找简单、可理解、长期经济特征稳定、十年或二十年后仍可能拥有强竞争力的业务。
   - 把公司分为：`Inevitable`（几乎必然长期主导）、`Highly Probable`（高度可能优秀）、`Impostor`（看似强大但易受攻击）、普通业务和商品型业务。
   - 检查护城河是否来自低成本、品牌习惯、分销系统、客户信任、规模经济、转介绍、监管或网络位置；并判断护城河是在变宽还是变窄。
   - 对 GEICO 式低成本业务，验证飞轮：低成本 -> 低价格 -> 吸引并留住好客户 -> 客户推荐 -> 更低获客成本 -> 更低成本。
   - 对零售业，按“每天都要聪明”的业务处理；竞争者会复制并超越，顾客每天被诱惑。没有杰出经理，优秀历史也可能突然坠落。
   - 对受管制转向非管制、成本结构僵硬的商品型业务，警惕 USAir 式错误：高级证券、低估值和悠久盈利历史都不能弥补成本无法降到竞争水平。
   - 对快速变化行业保持克制。作为公民欢迎创新，作为投资者只在能可靠判断长期经济性时行动。

5. 评估管理层、文化和激励
   - 只愿与诚实、能干、股东导向、热爱业务并懂得专注的经理合作。好的经理应像经营自己的企业一样经营，而不是像雇员一样完成指标。
   - 伯克希尔式所有权给经理高度自治：不干扰成功，不对优秀经理“教挥棒”。但自治的前提是经理可信、业务可理解、结果可衡量。
   - 检查管理层是否会在个人利益与股东利益冲突时偏向股东；这比商业能力同样重要。
   - 激励制度必须按具体业务经济性设计，简单、可衡量，并直接连接参与者的日常行动。不要用宽泛股权期权或集团股价奖励无法控制单元结果的经理。
   - 当业务占用资本显著时，把增量资本成本计入奖金，也奖励释放资本。激励要上下对称，不接受“正面归经理、负面归股东”的彩票式安排。
   - 对董事会和治理，问董事是否具备商业判断、投入程度和所有者导向；董事会应能代表缺席所有者评价 CEO，而不是做管理层的社交陪衬。

6. 检验资本配置和收购
   - 不看卖方预测。卖方通常知道更多，也会在“马走得好”的时候出售；华尔街乐观情景往往娱乐性高于教育性。
   - 不为战略规划、行业多元化、规模、交易刺激或 EPS 增厚而收购。每笔收购都必须和二级市场上优秀公司少数股权的可得价格比较。
   - 好收购的标准：业务经济性好、可理解、管理层优秀且留任、价格合理、卖方关心企业和员工、交易结构不稀释老股东内在价值。
   - 好业务通常产生超过内部再投资需求的现金。经理先在本业务内寻找高回报用途，剩余现金上缴，再由总部在全市场重新配置。
   - 分红、回购、并购、还债、持现金、发股都用同一标准：每一美元是否能增加至少一美元的长期每股内在价值。
   - 对可转优先股、结构性证券和“安全”的高级证券保持怀疑。若底层业务优秀，过度聪明的证券结构可能不如直接持有普通股；若底层业务糟糕，结构保护也有限。

7. 分析保险和浮存金
   - 浮存金是“持有但不拥有”的钱。用损失准备金、理赔调整准备金、假设再保险持有资金和未赚保费，加上或扣除相关应收、预付和递延项目来估算。
   - 浮存金成本由承保亏损或承保利润决定。长期成本低于替代资金成本时保险业务有价值；高于市场资金成本时，浮存金会变成负担。
   - 低成本、稳定增长的浮存金在经济上接近准权益，但不是股东权益；不能因为规模大就假设有价值。
   - 对原保险，重点看自愿保单增长、成熟业务承保利润、综合成本率、获客成本、续保、转介绍、定价纪律和准备金真实性。
   - 对巨灾再保险，接受年度结果剧烈波动。好年份不能证明业务优秀，真正糟糕年份不是可能性而是必然性，未知的只是时间。
   - 不追求利润平滑。宁要长期不平滑的 15%，不要为报表稳定牺牲后的平滑 12%。
   - 检查巨灾险三项优势：极端情况下确定能赔、灾后仍有可用承保能力、能迅速提供行业少有的大额保障。
   - 反向工程最坏情形，把巨灾损失、证券市场下跌、相关经营资产受损叠加起来看。若后果会重伤内在价值，就不要播下种子。
   - 警惕模型精确幻觉。无需知道精确概率才能承保，但必须在“惊喜几乎总是坏消息”的前提下定价，并拒绝费率不足的业务。

8. 审查会计质量、税务和成本
   - 把 GAAP 当作起点而非终点。采购会计摊销、商誉冲销、阶梯收购重估、证券市值计量和一次性减值都可能让报表偏离经济现实。
   - 对控股业务，展示“如果没有被收购本会怎样报告”的经营收益；采购溢价摊销通常不是现金成本，但收购时支付的价格是真成本。
   - 对利润下滑先分类：周期性问题、永久性行业退化、技术替代、成本结构失控、管理执行问题，还是会计口径变化。
   - 坚持“先报坏消息”。优秀管理层不把长期主义当作无法兑现结果的借口，也不通过会计平滑掩盖经济问题。
   - 税收是真实成本，但延迟纳税有复利价值。长期持有优秀企业能保留递延税负优势；频繁换仓会让相同税前复利变成较低税后复利。
   - 成本也是真实成本。总部费用、基金管理费、投行费、销售佣金和高换手都要看是否取得相称价值；低摩擦本身会增加股东回报。

9. 重新定义风险和组合
   - 把风险定义为持有期内税后购买力永久损失，而不是股价波动或 beta。真正的投资者欢迎市场波动，因为它提供低价买入好业务的机会。
   - 评估风险时依次看：长期经济特征能否判断、管理层能力能否判断、管理层是否会把成果交给股东、买入价格、税收和通胀。
   - 若不了解具体公司，使用低费率指数基金并分批买入比假装懂更理性。承认无知后，“笨钱”就不笨。
   - 若能理解少数 5-10 家价格合理、长期优势重要的企业，过度分散反而会降低思考强度、增加风险。
   - 只做容易题。若必须在复杂变化中寻找针，不如买眼前清楚可见的针。

## 输出格式

使用中文输出，结论先行，写成所有者备忘录而不是行情评论：

1. 一句话结论：买入/持有/观察/回避，以及最关键理由。
2. 能力圈判断：业务是否足够简单、稳定、可预测；哪些部分无法判断。
3. 内在价值路径：账面价值、市场价格、经营收益、look-through earnings、每股价值和关键假设。
4. 业务质量：Inevitable/Highly Probable/Impostor/普通/商品型，护城河来源及变宽或变窄。
5. 管理层与文化：诚信、能力、专注、自治、股东导向、激励制度和治理结构。
6. 资本配置：留存收益用途、回购/发股/分红/并购/还债/持现金与机会成本比较。
7. 会计与税务调整：非现金摊销、一次性项目、资本利得、准备金、递延税和真实经济成本。
8. 保险/金融专项：浮存金规模与成本、承保纪律、准备金、极端损失、杠杆和资金结构。
9. 风险和反证：会推翻结论的事实、最坏情形、行业变化、管理层失焦、过高价格和未知项。
10. 估值与行动：保守价值区间、安全边际、需要核实的数据和下一步决策。

## 判断准则

- 价格不是价值；账面价值也不是价值。价值来自未来可取出的现金。
- 每股内在价值是最终计分牌。规模、收入、资产、员工和交易数量都不是目标。
- 好业务的市场价短期可跑输业务；坏业务的证券结构短期可看似安全。长期结果由底层经济性决定。
- 不为宏观预测停下合理行动，也不为恐惧本身买入。恐惧只有在价格低于保守价值时才有用。
- 能用一小段话解释的大机会通常优于需要复杂模型才能成立的机会。难度分不计入投资成绩。
- 优秀业务可以承受一些管理错误；普通或商品型业务需要持续低成本和纪律；糟糕业务会吞噬好经理。
- 低成本是最干净的护城河之一，特别是当低成本能转化为低价格、增长和进一步成本优势时。
- 发行股票是在出售公司一部分。只有收到的内在价值不低于交出的内在价值，才不伤害老股东。
- 收购必须和二级市场优秀企业少数股权比较；若不愿以同样价格买股票，也要谨慎买整家公司。
- 对保险，先问浮存金成本，再问规模。免费或负成本浮存金有巨大价值，高成本浮存金会毁灭价值。
- 巨灾险和投资一样，常常要多年后才知道是否聪明；不要把连续好年景当作承保能力。
- 不要用 beta 代替风险判断。风险是税后购买力永久损失，波动常常是机会。
- 如果不愿持有十年，不要考虑持有十分钟。
