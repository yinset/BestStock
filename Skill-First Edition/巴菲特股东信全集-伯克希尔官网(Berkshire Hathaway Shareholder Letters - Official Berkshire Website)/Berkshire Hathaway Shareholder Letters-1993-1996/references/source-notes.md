## 1993年信提炼

- 每股内在价值比账面价值重要。账面价值是投入资本，内在价值是企业余生可取出的现金现值；伯克希尔账面价值只能作为低估的跟踪器。
- 市场短期投票、长期称重。Coca-Cola 与 Gillette 的业务收益和股价表现会短期错位，但长期由企业收益决定。
- 资本基数越大，保持高增速越难。15% 每股内在价值增长目标要用 look-through earnings 支撑，且必须先画靶再射箭。
- Dexter Shoe 案例说明伯克希尔不靠战略规划选行业，而是寻找好经济特征和好经理的组合；卖方用单一好企业换取伯克希尔一组好企业和递延税优势。
- 收购后仍让优秀经理按原方式经营。伯克希尔不教 .400 hitter 挥棒。
- 报告收益要把采购会计调整集中列示，以便看到业务如未被收购时的经营收益。
- Look-through earnings = 报告经营收益 + 重大参股公司未分配经营收益份额 - 假设分回时应缴税。Cap Cities 案例说明该口径保守，因为留存收益最终产生的资本利得远超假设金额。
- 延迟纳税有巨大复利价值。相同税前复利下，单一长期持有并在最后纳税远胜不断兑现并逐年纳税。
- 保险分析必须结合承保结果和浮存金可获得的长期无风险收益；低利率会降低浮存金价值，不能只比较历史综合成本率。
- 巨灾险的好年份容易误导。多数年份有利润并不代表赔率合理；真正损失来临时可能一次吞掉多年利润。
- 巨灾再保险优势来自 Ajit Jain、巨大资本、愿意且能够在极端情况下付款，以及能提供竞争者无法提供的大额限额。
- 投资组合应以“拥有业务”看待。对懂且长期优秀的公司，小股权应像全资子公司一样有耐心，不因短期获利而轻易卖出。
- 风险不是 beta，而是持有期内税后购买力永久损失。风险判断要看业务经济性、管理层能力、管理层是否把成果交给股东、购买价格、税收和通胀。
- 集中投资在理解清楚、优势持久、价格合理的 5-10 家公司，可能比传统分散更低风险；若不懂企业经济性，则低费率指数基金更合适。
- 公司治理有三种结构：无控股股东、控股股东兼经理、控股股东不参与管理。董事的价值取决于能否代表缺席所有者约束管理层。
- 公司慈善和总部成本体现所有者思维：公司钱是股东钱，支出要么与业务有关，要么应由所有者决定。

## 1994年信提炼

- 伯克希尔未来回报不会接近过去，原因不是方法失效，而是资本基数过大；大钱包是超额回报的敌人。
- 继续等待好球，不因现金多而降低标准。政治和经济预测是昂贵干扰，历史重大事件没有削弱 Graham 原则。
- 最优公式仍是：以合理价格买入底层经济性好、由诚实能干者经营的企业。
- 账面价值和内在价值可严重背离。大学教育例子说明，历史投入和未来增量现金流现值是两回事。
- Scott Fetzer 证明采购会计摊销可降低账面值和 GAAP 收益，但业务内在价值可能持续上升；高 ROE 不是靠杠杆、周期或垄断，而是经理把基本功做好。
- 管理层资本配置必须以每股内在价值为准，而非 EPS 是否增厚或短期账面是否增加。
- 大多数收购让被收购方、管理层和投行受益，却让收购方股东受损，因为收购方付出比收到更多的内在价值。
- 好业务通常产生超过内部需求的现金，因此 CEO 的资本配置能力对价值影响巨大。向投行和顾问询问是否该收购，存在天然偏差。
- 激励要按经理控制的业务设置。增量资本要收费，释放资本要奖励；上下对称才是真正的利益一致。
- 常规股票期权若不随留存收益提高行权价，会奖励仅仅踩水的经理，甚至鼓励压低分红。
- 浮存金价值取决于成本；伯克希尔多数年份浮存金成本为负，但巨灾险连续好年景不可外推。
- 巨灾险需要愿意接受利润波动。为平滑报表而放弃高长期回报，是次优策略。
- 普通股投资可用短段话解释：持久竞争优势、能干且股东导向的经理、合理价格。难度分不计入投资成绩。
- 买入应基于价格而非择时；若全资收购时不看 Dow、Fed 或经济预测，买少数股权时也不应改变方法。
- 先考虑加仓已知优秀企业，再找新投资。长期熟悉公司和产品有助于评估。
- USAir 错误说明，高成本、非管制商品型业务必须把成本降到竞争水平，否则高级证券和历史盈利都保护不了投资者；不必从亏钱的地方把钱赚回来。

## 1995年信提炼

- 1995 年股市大涨不应被误认为经营能力。伯克希尔真正进步是买入 Helzberg's、R.C. Willey 和 GEICO。
- 伯克希尔有“双管齐下”的资本配置优势：谈判买入 100% 好公司，或在公开市场买入一部分好公司。两者必须按同一所有权逻辑比较。
- 没有路线图本身是优势。不被战略计划束缚，能用机会成本判断每个动作。
- 收购中卖方预测不值得看。卖方知道更多，也会在业务看起来最好的时候卖。
- 收购必须和“在二级市场买世界最好企业的一小部分”比较，这一纪律能抵抗为了扩张而扩张。
- 好卖方关心企业、员工和长期归宿，通常比单纯拍卖出售的卖方更少意外。
- Helzberg's 表明，零售收购若没有好经理就像买没有电梯的铁塔；高单店产出是利润质量核心。
- R.C. Willey 表明零售是“每天都要聪明”的业务，竞争者会复制和升级，顾客每天被诱惑；好经理不可替代。
- 管理优秀者可以高度自治。总部应像希望股东对自己那样对经理，少干预、多信任、用结果检验。
- GEICO 的本质优势仍是 1951 年的直接销售低成本。低成本让低价格成为可能，低价格吸引和留住好客户。
- GEICO 也提醒：卖出可识别的伟大公司通常代价巨大；回购能在不增持的情况下提高持股比例。
- 浮存金若长期接近免费，经济上类似准权益。盈利由资产收益、负债成本和杠杆三者共同决定；低成本负债是价值来源。
- 巨灾险宁要不平滑的 15%，不要平滑的 12%。许多管理者追求平滑，伯克希尔因此拥有竞争优势。
- 费率不足时减少承保，不能为规模写错价。坏再保险合同像地狱，容易进去、无法出来。
- 承保人与出资人必须在下行和上行都对称，否则保险问题会长期隐藏后爆发。
- 对业绩下滑分清问题类型：鞋业偏周期性，报纸特许权逐步退化，World Book 受电子替代。坏消息必须先讲清。
- 可转优先股复盘说明，过度聪明的结构可能损害收益。Gillette 若直接买普通股会好得多；Salomon 占用管理时间远超经济意义。
- B 股发行的目的不是融资本身，而是阻止高费率 Berkshire 仿制基金向不成熟投资者销售，并让价格更接近内在价值。

## 1996年信提炼

- GEICO 阶梯收购导致会计重述，说明会计价值可与经济价值背离；同一资产在账面上可被写低，经济价值却增加。
- 估算伯克希尔内在价值用两个关键指数：每股投资资产和每股非投资经营税前收益。总部费用和慈善应纳入经营列。
- 成本重要。低总部费用和低销售摩擦让更多收益留给股东；“和股东一起赚钱，而不是从股东身上赚钱”是核心文化。
- 市场价格与内在价值越同步，进入和退出的股东之间越公平。管理层通过沟通和政策影响股东群体质量。
- KBS 与 FlightSafety 收购都来自偶然接触，但能快速行动是因为业务经济性和经理质量已在能力圈内。
- FlightSafety 案例说明，即便资本密集，只要经济性好、经理杰出、交易结构尽量减少发股，也可成为好收购。
- 保险浮存金是内在价值的重要组成，账面价值不能完整反映。GEICO 使免费浮存金继续增长的概率显著提高。
- 巨灾险糟糕年份不是可能性，而是确定性。持有人若会因大灾损失恐慌，就不该事后卖，而该事前不持有。
- 伯克希尔出售的是把客户波动转到自己账上的能力。极端时能付、灾后仍有容量、能立即报出巨大限额，是核心优势。
- 计算机模型可能制造精确幻觉。保险和投资一样，常常多年后才知道当初是否聪明。
- 反向工程风险：先问哪些后果无法承受，再避免播种。避免大额借款，并把巨灾最大损失控制在不会重伤内在价值的水平。
- GEICO 飞轮：低成本 -> 低价格 -> 好保单增长 -> 转介绍 -> 更低获客成本。激励只看自愿保单增长和成熟业务承保盈利。
- 激励原则在 GEICO 中最清楚：符合具体业务经济性、简单、可测、与日常活动直接相关；投资经理则按多年投资表现考核。
- Look-through earnings 再次用于纠正报告利润缺陷：被投资公司留存收益通常比股息更有价值，因为它们能高回报再投资。
- 公开市场投资和收购子公司本质相同：以合理价格买入优秀经济性和诚实能干管理层，然后只监控这些品质是否保持。
- 投资偏好不易发生重大变化的业务。See's 和 Coke 的产品、渠道会变，但购买动机和竞争优势长期稳定。
- `Inevitables` 是十年、二十年后仍大概率主导的公司；领导地位本身不够，GM、IBM、Sears 都曾看似不可动摇。每个 Inevitable 背后都有许多 Impostors。
- 即便好公司也可能买贵。过热市场中，价值追上价格可能需要很久。
- 更严重的问题是优秀公司管理层因傲慢或厌倦而偏离主业，收购平庸业务，让价值长期停滞。
- 多数投资者应买低费率指数基金。若自己选股，只需两门课：如何给企业估值，以及如何看待市场价格。
- 投资目标是以合理价格买入容易理解、5 年、10 年、20 年后收益几乎肯定大幅更高的企业。若不愿持有十年，不要持有十分钟。
- USAir 复盘强化同一教训：历史盈利和高级证券不能抵消行业放开竞争后的高成本结构；如果历史给出所有答案，富豪榜会都是图书管理员。
- 融资和投行费用不是天然坏事，关键是费用是否与价值相称、是否服务于股东目标，而不是服务于销售方佣金。

## 压缩成公司分析方法

1. 只在能力圈内估算未来可取出现金，拒绝复杂但不可预测的业务。
2. 用每股内在价值统摄账面价值、市场价格、经营收益、资本配置和发股回购。
3. 用 look-through earnings 穿透参股公司留存收益，排除会计噪声和一次性项目。
4. 购买优秀企业的一部分与购买整家公司是同一种行为，必须按机会成本比较。
5. 先看业务长期经济性，再看管理层，再看价格；证券结构不能拯救糟糕业务。
6. 优先低成本、品牌习惯、分销和稳定需求形成的护城河；避开快速变化和成本僵硬的商品型业务。
7. 管理层要诚实、能干、专注、股东导向；激励要简单、可控、上下对称并计入资本成本。
8. 保险业务先看浮存金成本和准备金，再看规模；巨灾险必须按多年和最坏情形判断。
9. 把风险定义为购买力永久损失，使用反向工程排除无法承受的尾部结果。
10. 最终只在价格低于保守内在价值并有安全边际时行动，同时写清会推翻结论的事实。
