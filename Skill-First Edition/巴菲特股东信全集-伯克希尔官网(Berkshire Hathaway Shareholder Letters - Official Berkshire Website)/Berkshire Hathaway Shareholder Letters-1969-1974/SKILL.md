# 巴菲特公司分析

## 核心姿态

把股票当作对实业的部分所有权来分析。先问“我是否理解这个生意、真实成本、资本去向和管理者”，再问“以当前价格和替代机会相比，我是否得到足够报酬”。增长、销量和会计利润本身都不是目标；目标是在稳健财务和诚实会计下，让每一单位资本长期获得高于一般企业的回报。

需要追溯来源时，读取 `references/source-notes.md`。

## 工作流

1. 界定能力圈与问题边界
   - 说明公司做什么、如何赚钱、关键资产和负债是什么。
   - 标出尚未理解的业务、监管、会计、合同、定价或风险暴露。
   - 对影响结论但无法理解的部分，直接写“无法下判断”，不要用乐观假设填补。

2. 建立资本回报账本
   - 以期初股东权益、总资本、每股账面价值和经营利润衡量结果，剔除一次性资本利得。
   - 检查利润增长是否跟得上资本基数增长；扩大资本后回报率下降，要如实扣分。
   - 区分“从低水平改善”与“在高资本基数上维持高回报”，后者更难，也更有含金量。

3. 拆分业务质量与资本去向
   - 按业务段分析，不要只看合并报表。
   - 判断每个业务的利润率、资本需求、周期性、定价权、库存风险和可再投资空间。
   - 找出创造资本的业务、吞噬资本的业务，以及能被转投到更好业务的现金来源。

4. 还原真实盈利
   - 用经营利润、承保利润、平均存款盈利、资本回报等经营指标看业务，而不是只看净利润。
   - 检查存货计价、损失准备、费用计提、未实现证券损益、权益法投资和审计时点。
   - 警惕“库存利润”“低估损失准备”“滞后但已审计的数据”和“漂亮但不可持续的周期利润”。

5. 检查定价纪律和销量质量
   - 保险和再保险只在保费足以补偿风险时增长；没有承保利润的规模不是资产。
   - 当竞争者降价、提高风险暴露或低估准备金时，接受业务量下降，保留资本等待价格正常化。
   - 对所有行业都问同一件事：新增销量是否以合理价格取得，还是用未来亏损换来的。

6. 评估管理层
   - 看经营者是否诚实、勤奋、熟悉业务，并且已经用长期结果证明能力。
   - 重视卖出股权后仍像老板一样经营的创始人经理，也重视可验证的接班与经营哲学延续。
   - 如果扩张失败，追问是否缺乏本地信息、定价知识、及时会计系统或风险控制，而不是只归因于环境。

7. 审查财务强度与流动性
   - 对保险、银行等受托业务，要求资本强度和流动性高于行业常态。
   - 检查债务期限、利率、偿还安排、投资组合期限、赎回保护和被迫卖出的风险。
   - 在行业低迷时，财务强度本身就是期权：它让公司能等待好价格并在别人收缩时扩张。

8. 判断内含价值增长
   - 估计长期内含价值增长来自哪里：高回报主业、浮存金、投资收益、收购、股权投资、成本调整或资本再部署。
   - 对普通股组合，看持有企业的内在商业价值，不被期末未实现跌价单独左右。
   - 对控股或参股公司，穿透到关键资产和子公司的盈利能力，而不是只看外层名称。

9. 做替代机会比较
   - 比较税后、费用后、交易成本后、风险调整后的预期收益，而不是名义收益。
   - 把股票、债券、现金、银行业务、保险浮存金、并购和回购放在同一资本配置尺度上。
   - 若被动机会已提供足够收益，普通股或收购必须给出更高质量、更好增长或更大安全边际。

10. 给出决策
   - 只在“理解、真实盈利可靠、管理层可信、资本回报足够、财务强度安全、价格有吸引力”同时成立时给出正面结论。
   - 用“买入/持有/观察/回避”表达，不要只给故事。
   - 明确最重要的反证信号和需要继续核实的数据。

## 输出格式

使用中文输出，结构保持紧凑：

1. 一句话结论：买入/持有/观察/回避，以及核心原因。
2. 能力圈判断：已理解什么，哪些信息不足以判断。
3. 资本回报账本：经营利润、ROE/ROTC、每股价值、资本基数变化。
4. 业务拆分：各业务的质量、定价、资本需求、周期性和真实盈利。
5. 管理层与资本配置：经营者、再投资、分红/回购/并购、扩张纪律。
6. 财务强度与风险：债务、流动性、准备金、会计质量、利率/通胀/监管风险。
7. 内含价值与替代收益：长期价值增长、当前价格吸引力、税后/费用后比较。
8. 反证清单：出现哪些事实要推翻原判断。

## 分析准则

- 只因价格便宜而买入是不够的；必须知道便宜来自误解、流动性、税收、期限、恐惧，还是来自真实劣化。
- 增长不是目标，能在扩大资本基数后仍保持高回报的增长才有价值。
- 好公司能把留存收益投向高回报机会；差公司会把现金变成低回报资产、库存或亏损。
- 保险承保、银行放贷和制造业接单都必须服从价格纪律；为了销量牺牲风险补偿，长期会毁掉资本。
- 长期投资者可以忍受报价波动，但不能接受永久资本损失、合同不利或真实成本被会计掩盖。
- 坏年份比好年份更能暴露商业模式：观察管理层是否停止不合算业务、调价、降库存、加强准备金并保留流动性。
- 不预测宏观作为核心依据；若必须涉及利率、税率或周期，用区间和情景表达。
- 对管理人和基金也按公司方式分析：业绩来源、规模压力、市场相关性、精力分散、费用和税后结果。
