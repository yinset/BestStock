# 巴菲特公司分析 1975-1978

## 核心姿态

把公司当作一项真实生意来研究，而不是把股票当作价格曲线来交易。先还原每个业务分部的经济现实，再判断资本回报、行业结构、管理层质量和价格是否同时成立。不要被合并报表、每股收益、单年资本利得、短期股价或“便宜资产”遮住真正的经营质量。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 先确定分析口径
   - 说明分析对象是整家公司、控股子公司、少数股权、保险公司、银行、零售商，还是混合控股公司。
   - 对控股公司和并表公司，拆开分部看：保险承保、保险投资收益、纺织、银行、零售、糖果、报纸、母公司利息、证券收益等不要混成一个平均数。
   - 区分经济所有权和会计列报。并表口径可能把100%拥有和部分拥有的业务合在一起，少数股权也会改变真正归属于股东的收益。

2. 用正确尺子衡量经营成果
   - 单年经营表现优先看经营收益相对期初股东权益的回报率，而不是EPS增长、收入增长或绝对利润。
   - 经营收益评估中剔除已实现证券收益和一次性因素；长期记录中再把已实现和未实现资本增值纳入每股内在价值变化。
   - 识别税收退款、周期性反弹、会计重述、并购并表等因素，避免把不可重复收益当作经营能力。
   - EPS增长本身不是成就。资本基数逐年增加时，普通储蓄账户也会让收益自然增长；真正问题是新增资本能否继续获得高回报。

3. 先判行业顺逆风
   - 问这门生意是在顺风中航行，还是在逆风中消耗管理层才华。行业结构往往决定长期回报上限。
   - 对商品化、资本密集、供给过剩的行业，默认长期回报贫乏。纺织业显示：低毛利、慢周转、高应收和高库存会把ROE压低，即使账面固定资产看似便宜也无济于事。
   - 对产品标准化、易复制、价格公开的行业，寻找成本优势、承保纪律、风险选择能力或特别优秀的管理层。保险业没有专利、位置、品牌隔离和差异化产品，人的判断会被放大。
   - 对低增长行业，不要自动否定；若资本需求低、现金回报高、管理层节制，低增长也可能产生好结果。

4. 拆解资本回报来源
   - 将ROE拆成利润率、资本周转率、杠杆和税率。不要只看利润率，也不要只看资产“便宜”。
   - 检查资本是否被应收账款、库存、设备更新或监管资本吞噬。高会计利润若需要持续大量新增资本维持，经济价值会被削弱。
   - 对低回报业务，要求它至少产生适度现金回报，并避免继续投入大量新固定资产；否则资本应转向更高回报机会。
   - 对高回报业务，允许其留存收益，只要新增资本仍能以有吸引力的回报率再投资。

5. 保险业务单独分析
   - 先看综合成本率：低于100代表承保盈利，高于100代表承保亏损。再看该结果是否来自真实定价能力，而不是准备金乐观。
   - 比较费率涨幅与损失成本涨幅。医疗、维修和“社会通胀”会让真实赔付成本持续上升；费率若追不上，当前盈利会转成未来亏损。
   - 特别审查长尾业务和再保险。结案滞后会推迟错误暴露，准备金自我欺骗会把行业费率压到不合理水平。
   - 把保费规模当作结果而非目标。价格不足时必须愿意收缩业务量；追求亏损保费会摧毁承保价值。
   - 分开看承保利润和投资收益。浮存金有价值，但只有在承保价格理性、准备金保守、财务强度足够时才是好资金。

6. 评估管理层
   - 先看诚实。优秀管理层会坦率报告坏消息、承认预测错误、解释分部真实表现，而不是用合并数字遮盖问题。
   - 再看纪律。保险经理要能在市场松动时拒绝坏价格；银行和零售经理要能长期控制成本；资本配置者要能拒绝低回报扩张。
   - 看主人翁意识。优先信任那些像拥有企业一样每天经营的人，他们不需要总部频繁干预，也不需要用复杂制度才会做正确的事。
   - 在标准化行业中，管理层差异特别重要；在强逆风行业中，优秀管理层也只能把结果从糟糕拉到尚可。

7. 以企业所有权标准选择股票
   - 对少数股权使用和整体收购相同的标准：能理解、长期经济特征有利、管理层诚实能干、价格相对私人买家价值非常有吸引力。
   - 不为短期股价行为买股票。若企业经营继续令人满意，价格下跌通常是以更好条件增持好生意的机会。
   - 公开市场有时能用远低于整家公司成交价的估值买到优秀企业的一小部分。控制权不是目的，优秀管理层在位时，被动持有可能比控制更好。
   - 集中持仓。若只找到少数符合标准的公司，就买少数；不要为了形式上的分散买一堆平庸标的。

8. 穿透留存收益
   - 对控股业务和参股公司都问同一个问题：留存的一美元，长期能否变成至少一美元的内在价值。
   - 若公司能高回报再投资，未分配利润虽不进入当前报表收益，也是真实经济利益。
   - 若公司资本需求低或管理层再投资记录差，利润应分红或在股价低于内在价值时回购；低回报留存会伤害所有者。

9. 检查财务强度和流动性
   - 保守融资和充足流动性让公司不必在坏时点出售资产，尤其适用于保险和银行。
   - 债券市值波动本身不是问题，前提是公司有能力持有到期且没有被迫出售需求。
   - 金融企业要额外检查资产质量、准备金保守性、期限错配、存款或保单负债稳定性，以及监管约束。

10. 最后才做估值和结论
   - 估值锚定私人所有者价值，而不是近期股价、短期盈利趋势或市场情绪。
   - 对每个核心假设写反证：行业是否可能更差、费率是否无法跟上成本、管理层是否会误配资本、会计收益是否高估经济收益。
   - 只有当业务能理解、行业长期特征可接受、管理层可信、资本回报真实、财务结构稳健、价格足够便宜时，才给出积极结论。

## 输出模板

按以下结构输出公司分析：

```text
1. 分析口径：控股/参股/混合控股/金融业务，使用哪些分部和所有权口径
2. 经营尺子：经营收益、期初权益ROE、资本占用、一次性项目和资本利得处理
3. 行业顺逆风：差异化、供需、资本密集度、价格传导、竞争行为
4. 分部经济：各分部利润、资本需求、现金贡献、少数股权和并表扭曲
5. 管理层：诚实度、成本纪律、承保或定价纪律、资本配置、主人翁意识
6. 保险/金融专项：综合成本率、费率充足性、准备金、浮存金、流动性和资产质量
7. 投资组合视角：少数股权、留存收益、集中度、市场价格是否提供机会
8. 估值：私人买家价值、当前价格折溢价、安全边际和关键反证
9. 结论：满足哪些标准、不满足哪些标准、应买入/观察/回避及原因
```

## 红旗清单

- 用EPS增长替代期初权益ROE。
- 用合并利润替代分部经济。
- 把资本利得、税收退款或周期反弹当作可持续经营能力。
- 在商品化、供给过剩、资本密集行业中假设长期高回报。
- 对保险业务只看保费增长，不看费率充足性、准备金和综合成本率。
- 管理层回避坏消息、用乐观预测替代事实、在坏价格下追求规模。
- 看到账面资产便宜就忽略低周转、低利润率和持续资本需求。
- 对优秀公司因短期股价下跌而恐慌，而不是复查商业进展和价格吸引力。
