# 巴菲特股东信 2016-2017 公司分析方法论

## 总原则

用企业主视角分析公司：目标不是解释季度利润，而是判断每股内在价值能否长期、稳健、低风险地增长。

优先回答三件事：

1. 这门生意是否能在较长时间内提高每股正常化盈利能力？
2. 管理层是否以股东资本为信托，按价格纪律配置资本？
3. 当前价格是否让继续持有人或买入者获得足够的长期胜率？

分析顺序固定为：

```text
正常化每股盈利能力 -> 商业模式与护城河 -> 资本配置 -> 财务真实度 -> 管理层品格 -> 价格与风险
```

不要从GAAP净利润、市场情绪、目标价、宏观预测或管理层调整后EPS开始。

## 一、先还原真实盈利

### 1. 区分经营成果和会计噪音

先把利润拆成三层：

- 经营利润：主营业务在正常环境中的税后盈利能力。
- 投资收益：股息、利息、被投企业留存收益最终转化的价值。
- 会计波动：已实现和未实现资本利得、一次性税收影响、减值或重估。

2017年信的核心警告是：新会计规则把股票未实现盈亏计入净利润后，GAAP底线会剧烈摆动，可能淹没真正重要的经营数字。分析时必须把投资组合市价波动与经营表现分开。

### 2. 正常化利润调整

按下列顺序调整：

- 剔除一次性税收收益或税率变化影响。
- 单列已实现和未实现投资收益，不把它们当作经营质量证据。
- 对收购形成的无形资产摊销做经济判断：品牌、客户关系、许可证等未必真实消耗；但技术、合同或会衰减的资产不能机械加回。
- 对重资产业务校正折旧：历史成本折旧可能低于维持竞争力所需资本开支，铁路等行业尤其如此。
- 把股权激励视为真实薪酬成本。
- 把经常出现的“重组费用”视为正常经营成本，除非公司清楚解释一次性重基准化。

可用公式：

```text
经济盈利 =
  GAAP净利润
  - 一次性税收/会计收益
  - 已实现和未实现投资收益中的非经营部分
  + 非经济性无形资产摊销
  - 维持性资本开支超过折旧的部分
  - 被错误剔除的股权激励、重组、准备金不足等真实成本
```

### 3. 每股是核心单位

最终落到每股正常化盈利能力，而不是公司总规模。并购、回购、发股、债务融资都必须检验是否提高长期每股内在价值。

## 二、识别商业模式

### 1. 轻资产高回报业务

优秀信号：

- 净有形资产需求少，却能产生高税后回报。
- 价格、品牌、渠道、服务或成本结构让竞争者难以复制。
- 增量资本仍能以高回报再投入。

分析动作：

- 计算税后利润对平均净有形资产的回报。
- 分开看各业务单元，避免高回报业务被低回报业务平均。
- 判断商誉背后是否是真正的经济商誉，而非高价收购后的会计残留。

### 2. 资本密集且受监管业务

典型对象：铁路、公用事业、能源基础设施。

优秀信号：

- 资产长期必要，需求抗周期。
- 债务与资产匹配，且不依赖母公司担保。
- 即使在糟糕年份，EBIT对利息覆盖仍有充分余量。
- 用低价格和高服务质量赢得客户、监管者和社会许可。
- 能持续投入巨额资本并获得合理回报。

分析动作：

- 用EBIT/利息，不用EBITDA/利息。
- 区分维持性资本开支和扩张性资本开支。
- 检查折旧是否低估真实维护成本。
- 判断监管关系是否建立在客户受益上，而不是短期讨价还价上。

### 3. 保险浮存金业务

浮存金的价值由四个变量决定：

- 规模：可投资资金有多大。
- 久期：是否稳定、长久、不会被挤兑。
- 成本：承保是否长期盈利，综合成本率是否低于100%。
- 风险：是否可能因准备金不足或巨灾暴露吞噬资本。

把优质浮存金视作“低成本甚至负成本的长期资金”，但不要把所有保险负债都当作资产。浮存金只有在承保纪律可靠时才有价值。

保险承保四条纪律：

1. 理解所有可能造成赔付的风险暴露。
2. 保守估计发生概率和损失金额。
3. 设定足以覆盖损失和费用并产生利润的保费。
4. 如果价格不够，愿意放弃业务。

重点警惕：

- 为了保费规模牺牲承保利润。
- 长尾业务准备金不足。
- 初始巨灾损失估计过低。
- 资产端追逐收益率，负债端却没有足够资本缓冲。

### 4. 金融和信贷业务

分析金融业务时，把资产负债期限、客户质量和周期压力放在利润率之前。

检查：

- 是否存在短借长贷、利率错配或流动性错配。
- 贷款客户在衰退、失业、离婚、死亡等压力下的违约脆弱性。
- 公司是否通过合理减损方案降低最终损失，而不是只追求账面利息。
- 母公司或集团是否能提供真正的长期资金优势。

## 三、检验护城河

护城河不是口号，而是能让企业长期保护经济利润的结构。

优先识别这些来源：

- 低成本结构：能以低于竞争者的成本交付同等或更好产品。
- 规模与密度：规模越大，单位成本、数据、服务网络或采购能力越强。
- 资本与信用能力：在别人受限时能承接大额、长期、复杂风险。
- 监管许可与社会信任：特别适用于公用事业、铁路、保险。
- 管理文化：分权、节俭、长期主义、愿意拒绝不合格业务。

压力测试：

- 如果竞争者投入大量资本，五年内能否复制该公司的成本、客户关系和回报？
- 如果行业价格下行，公司能否仍然盈利并扩大份额？
- 如果资本市场关闭，公司是否还能运营和投资？
- 如果监管者审视其价格和利润，公司是否能证明客户也受益？

GEICO式低成本护城河的判断：客户能清楚获得价格优势，公司因此持续获得市场份额；竞争者知道该优势，却难以跨越。

## 四、评估资本配置

### 1. 四个价值增长引擎

按2017年信的框架，企业价值增长来自四类动作：

1. 大型独立并购。
2. 与现有业务匹配的补强并购。
3. 内生销售增长和利润率改善。
4. 股票和债券投资收益。

分析公司时逐项判断：过去的资本是否流向了回报最高、风险最低、每股价值增厚最明确的地方。

### 2. 并购标准

合格并购必须同时满足：

- 持久竞争优势。
- 能干且品格高的管理层。
- 对经营所需净有形资产有良好回报。
- 有以吸引人回报继续内生成长的机会。
- 购买价格理性。

并购估值必须用全股权口径评估，不要因为廉价债务让EPS看起来增厚就放松价格纪律。协同效应只能当作额外惊喜，不能作为支付高价的理由。

### 3. 发股纪律

用股票收购等于把现有股东的一部分企业交给卖方。只有当交出去的价值少于得到的价值时才合理。

危险信号：

- 为了完成交易发行被低估的股票。
- 用“战略意义”掩盖价格过高。
- 高估收购对象，低估本公司股票。
- 交易完成后股数大幅增加，但每股经济价值没有同步增加。

### 4. 回购纪律

回购只在低于内在价值时增厚继续股东价值。价格高于内在价值时，回购会伤害继续股东。

回购前必须检查：

- 公司是否有足够资金保护和扩张核心业务。
- 是否有回报更高的外部投资机会。
- 回购价格是否显著低于保守估计的内在价值。
- 管理层是否公开说明价格纪律，而不是只宣布金额。

核心句：同一件事在一个价格上聪明，在另一个价格上愚蠢。

### 5. 现金和流动性

现金不是只有一个价值：

- 母公司可自由使用的现金价值最高。
- 保险子公司的现金受监管资本和分红限制，价值略低。
- 境外现金、受限现金、客户保证金或监管资本不能按同等自由度估值。

公司必须有能力在危机中不依赖银行额度、商业票据或市场善意。过剩流动性短期拖累收益，但能换来危机中的行动权。

## 五、判断管理层

### 1. 诚信

正面信号：

- 主动承认重大错误，并说明金额、原因和教训。
- 清楚解释GAAP和经济现实的差异。
- 不用“调整后利润”系统性排除真实成本。
- 不为了达成华尔街预期而管理利润。
- 让大小股东同时获得重要信息。

危险信号：

- 年年出现“非经常”费用。
- 把股权激励排除在成本之外。
- 依赖EBITDA回避折旧和资本开支。
- 每次并购都靠乐观预测和协同效应证明。
- 总能“刚好达标”。

### 2. 能力

考察管理层是否会说“不”：

- 对不合格保险价格说不。
- 对高价并购说不。
- 对过度杠杆说不。
- 对为了规模扩大而牺牲每股价值说不。

好的管理层不需要总部微观管理；他们把业务当作自己家庭唯一资产经营。

### 3. 股东导向

检查：

- 管理层和董事是否用自己的钱买入股票，且同时承担下行风险。
- 薪酬是否与长期每股价值相关，而非规模、收入或短期EPS。
- 信息披露是否优先服务长期股东理解，而非短期交易。
- 是否把留存收益视为股东托付：每留存1美元，长期至少创造1美元以上市场价值。

## 六、定义风险

风险不是短期波动，而是长期购买力或未来消费能力无法实现。

使用三层风险框架：

- 经营风险：生意是否会被竞争、技术、监管、客户行为永久削弱。
- 财务风险：债务、期限错配、流动性依赖是否会迫使公司在坏时点出售资产或融资。
- 行为风险：管理层或投资者是否会因恐惧、贪婪、费用诱惑、短期排名而做错事。

长期投资中，低收益长期债券不一定低风险；若收益率远低于企业权益回报和通胀，购买力风险可能更高。相反，以合理盈利倍数买入一篮子优秀、保守融资的企业，持有期越长，失败风险越低。

禁止使用杠杆作为长期持股的常规工具。优秀股票也可能短期下跌37%-59%；杠杆会把价格波动变成永久损失或错误决策。

## 七、费用和活动的拖累

分析任何资产管理产品时，把费用作为复利反向力量量化。

检查：

- 固定管理费、业绩提成、基金中基金二层费用、交易成本和税费。
- 管理人是否靠资产规模而非客户收益致富。
- 产品是否需要持续更换经理、风格和叙事来证明费用。
- 净收益是否长期超过低成本指数基金。

结论规则：大多数高费用主动管理在总体上无法战胜低成本被动组合，因为主动投资者整体在成本前只能等于市场，成本后必然落后。

## 八、估值与决策

### 1. 估值锚

使用多个锚交叉验证：

- 正常化经营利润和合理资本化倍数。
- 每股内在价值增长率。
- 净有形资产回报和可再投资空间。
- 保险浮存金的成本、久期和可投资价值。
- 被投企业留存收益的看穿价值。
- 现金、税负、受限资产和债务的真实经济价值。

不要用单年GAAP净利润、短期股价、分析师目标价或会计账面价值作为唯一锚。

### 2. 决策分类

输出必须给出明确分类：

- 买入：优秀或可理解的业务，价格显著低于保守内在价值，财务结构能承受坏环境。
- 持有：业务质量和管理层可靠，但价格安全边际一般。
- 观察：业务可能好，但关键变量缺证据。
- 回避：价格过高、杠杆脆弱、会计质量差、管理层不可信或护城河不可证。

### 3. 反向问题

在结论前回答：

- 如果市场关闭五年，还愿意持有吗？
- 如果股价下跌50%，是更想买还是被迫卖？
- 如果不能使用债务融资，这笔并购或投资还划算吗？
- 如果把所有调整后利润还原为真实成本，公司还便宜吗？
- 如果管理层预测全部打七折，价格仍有安全边际吗？

## 十、使用禁忌

- 不要把巴菲特案例机械套用为行业标签；必须回到经济结构。
- 不要把浮存金、商誉、品牌、协同效应自动视为资产；先证明其经济价值。
- 不要用EBITDA替代真实盈利。
- 不要把高杠杆下的EPS增厚当成价值创造。
- 不要忽略股权激励、重组费用、维持性资本开支和准备金不足。
- 不要因宏观恐惧放弃好价格，也不要因市场热情放弃价格纪律。
