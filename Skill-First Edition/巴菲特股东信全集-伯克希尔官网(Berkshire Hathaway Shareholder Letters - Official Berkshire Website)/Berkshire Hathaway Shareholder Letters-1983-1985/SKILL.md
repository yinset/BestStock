# 巴菲特公司分析 1983-1985

## 核心姿态

把股票、债券、控股公司和少数股权都当作企业所有权来分析。目标不是预测市场下一步，而是判断每股内在商业价值能否长期增长，以及当前价格是否给了足够好的进入条件。不要用规模、EPS、账面价值、流动性、交易活跃度或会计分类替代真实商业价值。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 先确定所有者口径
   - 说明分析对象是整家公司、控股子公司、少数股权、债券、保险业务，还是混合控股公司。
   - 用每股内在价值增长衡量成果，不用公司规模、总利润或一年市场报价衡量成果。
   - 把控股权和少数股权放在同一张机会成本表里比较：若同类优秀业务的少数股权价格更低，不要为了控制权支付过高溢价。

2. 从会计数字还原经济现实
   - 区分账面价值和内在价值。账面价值记录投入了多少资本；内在价值估算未来可取出的现金。
   - 分部看业务，不只看合并利润。混合控股公司必须拆开保险、制造、零售、媒体、投资收益、资本利得和一次性项目。
   - 年度已实现资本利得通常不能说明当年经营表现；它更像多年价值积累在出售日被会计确认。
   - 对商誉摊销保持怀疑。经营质量分析中忽略会计商誉摊销，关注无杠杆有形净资产能产生多少税后收益；收购分析中则永远以完整购买成本衡量回报。

3. 判断生意类型
   - 优先生意通常来自三类经济商誉：消费者特许权、非管制性政府特许权、持久低成本地位。
   - 好生意能用很少有形资产产生高收益，并把产品价值而非生产成本作为定价基础。
   - 商品型生意通常没有差异化，价格由行业供需决定；即使单个公司理性投资，行业整体也可能把成本节省全部传给客户。
   - 用竞争者测试：如果给你充足资本和优秀人才，你是否愿意正面竞争？若不愿意，说明对方可能有真正护城河。

4. 做通胀与资本需求测试
   - 问销售额和利润翻倍时，需要追加多少存货、应收、固定资产和维护资本。
   - 能在少量新增有形资本下提高名义利润的业务，经济商誉会随通胀上升；需要同步投入大量资本的业务，只是在原地维持购买力。
   - 不要迷信“实物资产抗通胀”。资产重、低回报的企业常被通胀迫使不断留存资金，却没有多余现金给所有者。

5. 区分自由盈利和受限盈利
   - 自由盈利可以按所有者意愿分红、回购、并购或再投资；受限盈利必须留在业务中维持销量、竞争地位和财务强度。
   - 对高资产/利润比业务，把被通胀、营运资本和固定资产吞掉的利润打折。
   - 对消费品和零售业务，不能只看美元销售额；必须看单位销量、同店销量、每单位成本和价格提升是否损害需求。

6. 检查行业结构
   - 纺织这类商品行业中，成本节省型资本开支常形成“集体理性、整体愚蠢”：大家都投钱，行业价格随之下降，回报仍然贫乏。
   - 主导型报纸的核心不是发行量，而是有效覆盖和渗透率。高渗透率使广告主几乎无法绕开它。
   - 报纸/媒体特许经营要同时看商业垄断力和管理层自我要求；市场可能不会惩罚差内容，所以品质要靠管理层主动坚持。
   - 对任何行业，先问“这艘船是不是会漏水”，再问管理层划船多努力。

7. 保险和再保险专项分析
   - 先看综合成本率、保费增长、赔付成本通胀、费用率、准备金发展和长尾风险。
   - 财险利润表只是“第一稿”。赔付成本可能多年后才暴露，IBNR和准备金修正会让过去利润重写。
   - 警惕“行尸走肉”保险公司：净资产已不足却仍用低价承保换现金流，既扭曲行业价格，也可能通过保证基金把损失转嫁给健康公司。
   - 保险容量是心理容量和资本容量，不是物理产能。资本一旦涌入，价格改善往往很快被新容量破坏。
   - 财务强度是保险业务的护城河。保单只是承诺，买方在恐惧期会为确定能付款的承保人付费。
   - 区分毛承保能力和净承保能力。只在价格正确、风险不高度相关、且公司能用自有资本承受损失时，才承接大额风险。

8. 评估管理层
   - 管理层应像所有者合伙人一样思考：自己持有大量股份、诚实报告坏消息、拒绝会伤害长期价值的扩张冲动。
   - 对“除某因素外表现很好”的叙述保持警惕。若某类例外反复出现，它就是业务的一部分。
   - 奖励机制要按管理者可控制的业务单元表现支付，而不是机械绑定全公司股价。
   - 固定价格长期期权必须纳入留存收益和资本成本因素；否则管理层仅靠保留股东资金就能获利。
   - 管理层可以拿高奖金，但奖金应来自真实业绩、合理门槛和自己负责领域的成果。

9. 审查资本配置
   - 每一美元留存收益都要接受五年滚动检验：是否至少创造一美元市场价值或内在价值。
   - 回购只有在价格显著低于内在价值、且公司财务稳健时才创造价值；绿色勒索式回购是在拿全体股东的钱赎买个别股东。
   - 分红政策要解释，而不是套行业惯例。若留存资本的预期回报低于股东可得机会成本，应分红或回购。
   - 发行股票等同于卖出公司一部分。只有收到的内在商业价值不低于交出的内在商业价值，才可以发行。
   - 债券也当作一门“特殊生意”估值：看投入资本、税后现金收益率、违约风险、上行封顶和通胀毁灭风险。
   - 集中投资只适合财务强度极高、理解充分、价格吸引且能承受错误的情境。

10. 做投资或收购判断
    - 先找好购买条件，不要把收益建立在“未来会有好买家”上。
    - 优先选择简单、可理解、持续盈利、低债务高回报、管理层在位且价格明确的业务。
    - 不碰转型、恶意收购、拍卖式销售、纯概念新业务、看不懂的技术复杂业务。
    - 对大额少数股权，必须同时满意业务经济性、管理层能力、管理层品格、价格和治理安排。
    - 对好公司也要检查价格。价格过高可以抵消多年经营进步；市场价格低于价值才是朋友。

## 输出格式

使用中文输出，结论先行，结构紧凑：

1. 一句话结论：买入/持有/观察/回避，并说明核心理由。
2. 所有者口径：分析对象、控股/少数股权/债券/保险属性、每股价值指标。
3. 经济收益还原：分部收益、一次性项目、商誉摊销、资本利得、未报告留存收益。
4. 生意质量：经济商誉来源、定价权、成本优势、资本需求、通胀承受力。
5. 行业结构：商品化程度、容量纪律、渗透率/有效覆盖、竞争者行为。
6. 管理层：诚实度、所有者心态、资本配置记录、激励是否对齐。
7. 资本配置：留存、分红、回购、并购、股份发行、债务、现金和替代机会。
8. 估值：内在价值区间、价格/价值关系、安全边际、关键假设。
9. 反证清单：哪些事实会推翻判断，下一步必须核实什么。

## 判断准则

- 投资最聪明的时候，是最像企业经营者的时候。
- 账面价值和重置成本不是价值本身；无法赚取合理回报的资产可能只值废铁价。
- 好业务不等于好投资；支付的完整价格决定回报。
- 增长只有在增量资本回报高时才有价值；靠更多资本堆出的利润增长不值得喝彩。
- 经济商誉真正强大的业务，能把大量利润从主业中释放出来，交给所有者再配置。
- 差行业里的优秀管理层通常仍输给行业结构；一艘长期漏水的船应换掉，而不是持续补洞。
- 对保险公司，准备金保守性、财务强度和承保纪律比保费规模重要。
- 对回购和股份发行，用内在价值而非EPS增厚/稀释来判断。
- 对管理层，听其言不如观其资本配置、坏消息披露和自我激励安排。
- 对市场报价，欢迎它提供机会，不要让它替你做判断。
