# 巴菲特公司分析 1957-1960

## 核心姿态

把股票当作企业所有权和企业事件权利的组合来分析。不要把精力放在预测市场涨跌上；重点寻找价格明显低于保守内在价值、下行有保护、价值会继续累积、并且存在价值释放路径的证券。

把1957-1960年合伙人信压缩成一句话：在能力圈内买入被市场冷落但价值清楚的公司，优先要求防守性强、折价足够、催化剂可等待或可创造；用长期相对业绩检验自己，而不是用单年行情证明自己。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 先校准市场背景和机会稀缺度
   - 判断整体市场是否明显高于、低于或接近长期投资价值，但不要据此做短期预测。
   - 市场越高，越提高对安全边际和事件隔离性的要求；市场越低，普通低估证券通常越多。
   - 宽基指数可能误导。看指数涨跌时，同时检查成分股广度、投资公司表现、股息和估值情绪。
   - 不要接受“新时代估值”。如果结论依赖大众相信股票必然轻松赚钱，应直接降低信心。

2. 给机会分类
   - `普通低估证券`：利润来自价格低于保守内在价值，最终由市场纠偏。
   - `Workout/特殊情形`：利润来自明确公司行动，如出售、并购、清算、要约、资产分离；核心风险是事件失败，而非大盘涨跌。
   - `控股/主动型价值释放`：通过大比例持股、投票权、董事会影响或股东联盟，缩短低估纠正时间。
   - `资产转换/隐藏资产`：市场只看到衰退业务，却忽略投资组合、可出售资产、税务结构或可分离价值。
   - 说明机会属于哪一类。混合机会要拆开分析，不要把普通低估误写成确定性事件。

3. 做保守内在价值拆解
   - 先用最朴素的价值来源估算：正常化盈利、净资产、可出售证券、清算价值、可分配现金和可独立出售的业务。
   - 对资产型公司做每股拆解：市场价格、投资组合价值、经营业务价值、潜在税负和交易成本分开列示。
   - 对盈利型公司看每股盈利能力、留存收益是否继续增加价值，以及不分红是否只是压低市场价格而非损害内在价值。
   - 用区间而不是单点估值。只有价格明显低于保守区间下沿，才称得上安全边际。

4. 检查防守性和永久损失风险
   - 把风险定义为永久性本金损失，不把短期报价波动本身当作风险。
   - 优先寻找强防守特征：资产覆盖、稳定盈利、低衰退敏感性、信息或区域垄断、优秀管理层、合理资本结构。
   - 问最坏情形下价值如何毁掉：业务长期衰退、资产无法变现、催化剂失败、治理僵化、资本被错误配置、杠杆或税务吞噬折价。
   - 如果下行保护主要来自“市场会继续喜欢它”，停止分析。

5. 判断价值释放路径
   - 写清楚价值如何被看见或兑现：并购、合并、清算、要约、分拆、资产换出、董事会改变、股东联盟、经营重组或时间带来的价值累积。
   - 区分“可等待的催化剂”和“需要自己创造的催化剂”。前者看概率和时间，后者看持股比例、投票权、盟友、成本和阻力。
   - 时间可以不精确，但逻辑要成立。若可能等十年，价值必须在等待中继续增长，不能只是原地便宜。
   - 对事件型机会，单独估算成功收益、失败损失、完成时间和年化回报。

6. 评估管理层、董事会和所有者激励
   - 看管理层是否能干、诚实、愿意把价值交还给股东，还是被董事会、客户关系或惯性压住。
   - 检查董事和管理层持股。重要决策者持股极少，却领取费用、维护现状或代表客户而非股东时，要提高警惕。
   - 区分经营管理能力和资本配置能力。好业务可能被沉睡的资产组合掩盖，投资组合也可能让董事会逃避经营改善。
   - 偏好利益一致的结构：管理者和股东同涨同跌，费用安排不鼓励无意义规模扩张。

7. 决定仓位、买入方式和保密性
   - 仓位由折价幅度、下行保护、价值释放确定性、资金占用时间和替代机会共同决定。
   - 当风险很低、价值差距很大且影响力随持股比例提高时，可以集中持有；不要用许多平庸小仓位掩饰理解不足。
   - 建仓期希望价格不涨，甚至下跌。对流动性差的公司，耐心、小心和保密本身是投资优势。
   - 若小额买盘就会推高价格，必须说明建仓计划；公开讨论持仓可能直接损害收益。

8. 比较机会成本和退出条件
   - 新机会必须打败现有最强机会。不是“仍然便宜”就一定继续持有，而是相对下一笔资本用途是否更好。
   - 当折价明显收窄、催化剂兑现、风险上升，或出现更好且确定性更高的替代机会时，考虑卖出。
   - 卖出价格不必等到完整内在价值；如果剩余折价不足以补偿时间和风险，资本应转移。
   - 不因市场预测而卖出低估资产，也不因市场兴奋而买入缺少安全边际的资产。

9. 用长期相对业绩计分
   - 单年、半年和建仓初期表现不能证明方法有效或无效；至少用三到五年，并同时经历强市和弱市。
   - 预期画像应诚实：在下跌或平淡市场中表现较好，在强劲牛市中可能只能持平甚至落后。
   - 用含股息的指数或合理替代基准比较，并说明费用、税负、现金流入流出和市场计价口径。
   - 一年亏15%而基准亏30%，可能比自己和基准都涨20%更成功；核心是相对“标准杆”是否持续胜出。

## 输出格式

使用中文输出，结论先行，写成所有者备忘录：

1. `一句话结论`：买入、观察、回避、等待建仓、继续持有或卖出，以及最关键理由。
2. `机会类型`：普通低估、Workout、控股/主动型价值释放、资产转换，或混合。
3. `市场与价格背景`：当前价格为何可能错、市场情绪是否误导、指数是否有代表性。
4. `内在价值拆解`：正常化盈利、资产价值、投资组合、经营业务、税负和保守价值区间。
5. `防守性与永久损失风险`：下行保护是什么，哪些路径会永久毁掉价值。
6. `价值释放路径`：催化剂、时间、概率、失败情景和等待期间价值是否继续增长。
7. `治理与激励`：管理层、董事会、股东结构、持股和资本配置行为。
8. `仓位与交易计划`：适合集中还是小仓位，如何建仓，何时不应公开或追价。
9. `机会成本与退出`：与替代机会相比是否仍值得，卖出或换仓条件。
10. `需要核验`：缺失数据、最该阅读的文件、最可能推翻结论的事实。

## 判断准则

- 市场价格会改变收益时间表，但不等于内在价值本身。
- 便宜必须和防守性相连；只有折价、没有价值保护，不是安全边际。
- 好机会常在价格沉闷、流动性差、短期业绩不好看时出现。
- `Workout` 的风险是事件失败；普通低估证券的风险是价值判断错或价值被长期破坏。
- 能成为最大或重要股东时，持股本身可能缩短价值释放时间。
- 管理层和董事会不持股时，不能假设他们会像所有者一样行动。
- 等待不是浪费，只要内在价值在等待中增长，且替代机会不更好。
- 高涨市场中找不到足够机会时，不要降低标准；提高事件隔离性、持有现金或等待都可以是行动。
- 长期表现必须用相对基准衡量，但不要把每年稳定跑赢当作合理预期。
- 若资料不足，不要给出巴菲特式确定结论；列出需要补充的事实和反证。
