# 伯克希尔公司分析方法论（2018-2019股东信精华）

## 使用原则

使用本 skill 时，把自己放在长期所有者的位置。不要把股票当作价格跳动的符号，而要把它当成一项企业所有权；不要被 GAAP 净利润、季度波动、短期股价、宏观预测和投行话术牵着走，而要追问：这家企业未来长期产生、保留并再投资现金的能力，是否能持续扩大每股内在价值。

分析必须围绕六个根问题展开：

1. 真实经营盈利能力是多少，哪些会计数字遮蔽了经济现实？
2. 企业能否把留存收益以高回报再投资，或通过回购提高每股价值？
3. 主要业务是否拥有持久、有利、可理解的经济特征？
4. 管理层是否诚实、能干、节制，并从留任股东而非离场股东或华尔街的角度决策？
5. 公司是否能在信用枯竭、市场暴跌、巨灾或行业冲击中保持生存和进攻能力？
6. 当前价格是否低于保守估计的内在价值，并留有安全边际？

## 一、先清除会计噪音

### 1.1 不要把 GAAP 净利润当作核心现实

2018年后，美国会计规则要求把股票投资的未实现涨跌计入利润表。伯克希尔的例子显示，这会让报告利润剧烈摆动：2018年市场下跌时净利润被压低，2019年市场上涨时净利润被抬高，但企业的真实经营价值并没有按同样节奏跳动。

分析公司时先拆分净利润：

- 经营利润：来自主营业务的持续盈利，是首要关注对象。
- 已实现投资收益：可能重要，但时间不规则。
- 未实现投资收益或损失：对会计利润影响巨大，但不等于当期经营表现。
- 减值、税率变化、一次性损益：必须解释其经济含义和可重复性。

输出时明确写出：报告利润为什么可能高估或低估真实盈利能力。

### 1.2 拒绝“调整后 EBITDA 崇拜”

伯克希尔在2018年信中特别批评调整后 EBITDA。分析中必须把真实成本放回企业：

- 股权激励是成本，不是股东送给管理层的礼物。
- 重组费用常常反复出现，不能机械加回。
- 折旧通常是真实经济成本，尤其是铁路、能源、制造、租赁等资本密集业务。
- 总部费用、利息、税、维护性资本开支都是真实负担。
- 收购产生的某些无形资产摊销可能不是真实经济成本，但要逐项判断，不能把所有摊销一概加回。

正确做法：

1. 对轻资产或收购型业务，区分真实摊销和会计摊销。
2. 对重资产业务，比较折旧与维护性资本开支；若维护性资本开支长期高于折旧，下调经济利润。
3. 对管理层给出的调整利润，逐项问：这项成本是否由股东真实承担？

### 1.3 账面价值可能越来越失真

2018年信中，伯克希尔放弃长期使用的每股账面价值指标。原因是：

- 伯克希尔从以股票资产为主，变成以经营企业为主，经营企业的价值通常不会随市场价值上调入账。
- 成功收购和内部成长常被历史成本低估，失败收购却可能通过减值及时体现。
- 当公司以高于账面价值但低于内在价值的价格回购股票时，每股内在价值上升，每股账面价值下降。

因此，分析成熟的经营型公司时，不要把账面价值等同内在价值。账面价值只是在金融资产占比高、资产可市场化、会计记录接近现实的情况下才有较强参考意义。

## 二、用“森林”而不是“树枝”看公司

### 2.1 先按经济板块拆分

复杂公司不能用一个市盈率粗暴覆盖。先把它拆成几片“森林”，再分别估值。

| 板块 | 核心问题 | 关键指标 |
| --- | --- | --- |
| 控股经营业务 | 是否持续产生真实经营利润，并能以合理资本需求成长 | 税后经营利润、净有形资本回报、维护性资本开支、定价权、现金转化 |
| 股票投资或少数股权 | 这是一组优质企业的部分所有权，还是一篮子交易筹码 | 应占利润、分红、被投资公司留存收益、回购、杠杆、税后潜在收益 |
| 合营或权益法投资 | 报表价值与市场价值是否偏离，治理权和退出条件如何 | 应占利润、市场价值、账面价值、控制权、减值风险 |
| 现金和固定收益 | 是战略储备还是低收益拖累，是否足以抵御冲击 | 现金规模、短债质量、最低安全现金、机会成本、流动性 |
| 保险或类保险资金 | 浮存金是否长期、低成本、可投资，承保是否有纪律 | 浮存金规模、承保利润、综合成本率、赔付期限、巨灾压力 |

估值时先分别给出每片森林的价值范围，再扣除必要税负、债务、少数股东权益和其他负担。

### 2.2 控股企业与少数股权要统一为“企业所有权”

伯克希尔反复强调，持有上市公司股票不是持有代码，而是持有企业的一部分。分析一家公司持有的股权投资时，必须穿透到被投资企业：

- 被投资企业的净有形资本回报是否优秀？
- 它们是否用过高债务制造回报？
- 它们留存收益后，是扩张业务、提升效率、还是以低估价格回购股份？
- 母公司只确认分红，未确认的留存收益是否在真实地增加母公司价值？
- 若未来卖出，需要扣除资本利得税。

对长期股权投资，优先计算“归属经济利润”：分红加上应占留存收益，而不是只看报表确认的分红收入。

### 2.3 整体可能大于部分之和

伯克希尔的价值不仅来自单个资产，还来自把这些资产放在同一实体中的制度优势：

- 可以在不同业务间客观配置大量资本。
- 可以用低成本、长期稳定的资金支持资产。
- 可以降低单一业务风险。
- 可以减少总部摩擦和官僚成本。
- 可以在税务和流动性上获得长期优势。

分析多元控股公司时，不要只做静态分部估值，还要判断总部是否真的创造资本配置和韧性价值。如果总部只是加管理层、加费用、加并购冲动，则应打折。

## 三、留存收益是复利发动机

### 3.1 留存收益的价值取决于再投资回报

2019年信把留存收益放在中心位置。优秀企业不把全部盈利分出，而是把一部分利润留在企业内，以复利方式扩大未来盈利能力。

分析时回答：

1. 公司过去留存了多少利润？
2. 留存利润投向了哪里：内部项目、补强收购、大型并购、回购、偿债，还是低效扩张？
3. 每一元留存收益带来了多少新增市场价值、盈利能力或每股价值？
4. 留存收益是否被糟糕并购、低回报资本开支、库存、应收款或官僚系统吞噬？
5. 如果管理层没有高回报机会，是否愿意分红或回购，而不是为了规模扩张而扩张？

核心判断：留存收益不是天然属于股东的财富增长，只有被高回报配置后才是复利发动机。

### 3.2 优先投资已有优秀业务

伯克希尔2019年信明确说，留存资金首先应投入已有的多元业务。对任何公司，都先看有机再投资机会：

- 现有业务是否还有广阔、可理解、可预测的扩张空间？
- 增量资本回报是否接近或高于历史回报？
- 增长是否需要牺牲价格、信用质量、服务质量或长期声誉？
- 资本开支是维护竞争力，还是创造新增盈利能力？
- 管理层是否能区分维护性资本开支和成长性资本开支？

内部高回报再投资通常比大型并购更可靠，因为管理层更了解业务，执行摩擦更低。

### 3.3 部分所有权也能享受留存收益

对上市公司少数股权，报表只显示收到的分红，但未分配利润仍在被投资企业中为股东工作。分析被投资公司时要看：

- 分红率和留存率。
- 留存收益投入后的回报。
- 回购是否在低估价格进行。
- 回购后母公司的持股比例是否被动上升。
- 被投资企业是否拥有长期可再投资空间。

当一家优秀企业盈利增长、股份数下降、估值合理时，长期所有者通常会受益。

## 四、优质企业的三道门槛

2019年信给出伯克希尔寻找新企业的三条标准：

1. 经营所需净有形资本能产生良好回报。
2. 由能干且诚实的管理者经营。
3. 价格合理。

使用时不要跳过任何一项。好公司买太贵，也会成为差投资；便宜公司缺乏持久经济优势，可能长期吞噬资本；好价格配坏管理层，结果常常更糟。

### 4.1 净有形资本回报

重点不是会计净资产回报，而是业务真正需要的净有形资本能产生多少税后盈利。

检查：

- 业务是否需要大量存货、应收款、固定资产或监管资本。
- 折旧与维护性资本开支是否匹配。
- 无形资产中哪些是真正经济资产，哪些只是会计记录。
- 高回报是否来自品牌、成本、网络、规模、数据、监管位置或客户习惯，而非短期会计处理。
- 高回报是否由过高杠杆制造。

### 4.2 管理层能力与诚实

能干但不诚实的管理层不合格；诚实但无能的管理层也不能托付大量资本。观察：

- 是否坦率解释失败，而不是用一次性因素或调整口径掩盖。
- 是否承认收购错误和资本配置错误。
- 是否把股东资金当作自己的长期资本。
- 是否抵制季度数字、市场预期和投行建议的压力。
- 是否愿意在没有合理价格时按兵不动。
- 是否培养继任者和分权系统，而不是让公司依赖个人英雄。

### 4.3 合理价格

价格必须和企业质量一起判断：

- 优秀企业若价格荒唐，可能让投资者等待很久才能得到合理回报。
- 普通企业即使便宜，也可能因资本低效和竞争侵蚀而不值得长期持有。
- 对长期持有者，最终投资表现会逐渐接近企业表现，但买入价格决定起跑线和安全边际。

## 五、保险与浮存金

### 5.1 浮存金不是普通负债

财险公司先收保费、后付赔款，因此持有大量浮存金。若浮存金长期稳定、成本低、甚至伴随承保利润，它在经济上优于普通债务。

判断浮存金质量：

1. 规模是否随保费长期增长。
2. 即使下降，是否会缓慢下降，而非被客户挤兑式抽走。
3. 承保是否长期盈利，至少是否接近成本为零。
4. 赔付周期是否长，损失估计是否保守。
5. 公司是否有足够现金、资本和多元盈利承受巨灾。

### 5.2 承保纪律高于增长冲动

浮存金的诱惑会让保险行业竞争激烈，甚至整体承保亏损。分析保险公司时，不能只看保费增长和投资收益，必须先看承保质量：

- 是否为了市场份额低估损失成本？
- 是否在利率低迷时追逐低质量债券或不流动另类资产？
- 赔付风险是否需要多年甚至几十年才暴露？
- 巨灾、网络攻击、长期责任险等尾部风险是否可能造成资本损失？
- 公司在巨灾后是被迫收缩，还是能继续写入优质业务？

优秀保险公司的核心不是胆子大，而是风险评估、定价纪律和资本韧性。

### 5.3 投资弹性来自资本实力

低利率环境会降低大多数保险公司浮存金的投资价值，因为它们的资产配置通常偏向高等级债券。伯克希尔的优势在于：

- 巨额资本。
- 大量现金。
- 多元非保险盈利。
- 可在行业受限时配置更广泛资产。

分析类似公司时，要判断投资弹性是否真实存在。若公司用高杠杆、低流动性或低信用资产追逐收益，浮存金优势可能变成风险。

## 六、资本结构与财务堡垒

### 6.1 少用债务

债务多数时候会提高股东回报，但在罕见且不可预测的信用枯竭时可能致命。分析时记住：不要为了不需要的收益，冒失去已有且需要之物的风险。

检查：

- 债务是否放在能承受它的业务实体内。
- 子公司债务是否由母公司担保。
- 业务在衰退期是否仍能产生充足现金。
- 短债、抵押品追缴、可赎回负债、衍生品和表外承诺是否造成流动性压力。
- 利息覆盖使用 EBIT 或税前经营利润，不使用 EBITDA 粉饰。

### 6.2 现金不是闲置，而是生存权和选择权

伯克希尔长期承诺持有最低现金缓冲，目的是在外部灾难中不短缺现金。分析公司现金时，区分三类：

- 必需现金：维持信用、监管、营运和灾难韧性。
- 机会现金：市场恐慌或并购机会出现时可部署。
- 冗余现金：长期无合理用途，可能需要分红或回购。

强公司宁可牺牲一点短期回报，也不应把现金安全边际压到危险水平。

### 6.3 递延税款和浮存金是特殊资金来源

伯克希尔除债务和股权外，还有两类重要资金来源：

- 浮存金：账面为负债，但若长期低成本并伴随承保利润，经济价值很高。
- 递延所得税：未来要付，但当前无息使用，尤其来自未实现投资收益和加速折旧。

分析时不要机械把所有负债等同看待。要判断负债的期限、成本、可赎回性、现金流压力和与资产的匹配程度。

## 七、回购纪律

回购只有在两个条件同时满足时才创造价值：

1. 股票价格低于保守估计的内在价值。
2. 回购后公司仍保有充足现金和韧性。

分析公司回购时：

- 计算回购价格相对内在价值的折扣，而不是只看回购金额。
- 判断管理层是否为了托底股价、提高 EPS 或抵消股权激励而回购。
- 检查回购是否牺牲了必要现金、偿债能力或高回报再投资机会。
- 关注股份数是否真正下降。
- 要求公司提供足够信息，让卖出股东和留下股东都能理性判断价值。

回购是价格敏感的资本配置行为，不是无条件的股东回报口号。

## 八、收购与资本配置

### 8.1 收购最容易让买方做梦

2019年信把收购比作婚姻：开头充满期待，现实常常不同。分析并购时保持怀疑：

- 管理层是否高估协同效应？
- 是否用过高价格购买普通业务？
- 是否忽视文化、激励、客户流失和资本需求？
- 交易顾问是否有天然促成交易的激励？
- 董事会是否听到足够强的反方意见？

好管理名声往往来自买到好业务，而不是把坏业务管理成好业务。

### 8.2 让优秀业务自然扩大资本占比

伯克希尔的经验是：差业务通常停滞，逐渐占用更少资本；好业务常常成长，并找到更多高回报再投资机会，最终占据更大资本比例。

分析组合型公司时：

- 识别哪些业务在消耗资本却不成长。
- 识别哪些业务能以高回报吸收新增资本。
- 判断总部是否让资本自然流向赢家，而不是用平均主义预算保护弱业务。
- 不要只看收入占比，要看资本占用和增量回报。

## 九、治理与董事会

### 9.1 董事会最重要的任务是选对 CEO

2019年信强调，董事会的根本挑战是找到并留住一个有能力、有诚信、愿意把职业生命投入公司的 CEO。选对后，董事会需要做的事反而少；选错后，流程再多也救不了公司。

分析董事会时，重点看：

- CEO 是否具备诚信、能力和长期承诺。
- 董事是否懂商业，而不只是懂流程。
- 董事是否真正代表所有者。
- 董事是否有用自己的钱买入股票。
- 董事薪酬是否高到影响独立性。
- 董事会是否敢挑战 CEO 的薪酬、并购和会计处理。

### 9.2 警惕“形式独立”

许多董事名义独立，却经济上依赖董事费、渴望更多董事席位，因而不愿冒犯 CEO。真正有价值的治理来自：

- 业务判断。
- 所有者心态。
- 对公司有具体、长期、强烈的兴趣。
- 能在关键时刻说“不”。
- 不被顾问、投行和管理层议程牵着走。

董事会不是流程展示台，而是股东资本的守护者。

### 9.3 反对为“达标”操纵数字

伯克希尔不设公司级月度利润目标，也不让季度数字主导文化。分析管理层文化时，寻找这些迹象：

- 是否提供季度指引并围绕“达标”行动？
- 是否通过渠道压货、释放准备金、推迟费用、调整假设来满足市场预期？
- 是否频繁改变非 GAAP 口径？
- 是否把一次小的会计修饰合理化，最终形成组织性欺骗？

优秀文化让真实数字自然流向股东；糟糕文化让组织为数字服务。

## 十、继任、分权与文化

伯克希尔2018年把 Ajit Jain 和 Greg Abel 分别放在保险和非保险业务核心位置，2019年又强调公司已为巴菲特和芒格离任做好准备。分析公司长期价值时，必须评估制度是否能超过个人。

检查五个因素：

1. 资产是否分布在多种高回报业务中，而非依赖单一产品或人物。
2. 控股业务是否放在一个能产生持久经济优势的实体内。
3. 财务是否能承受极端外部冲击。
4. 关键经理人是否热爱业务，而不只是追求薪酬或名望。
5. 董事是否守护股东利益和公司文化。

好的分权不是放任，而是在清晰的资本配置、诚信和风险边界下给优秀经理人空间。

## 十一、投资组合与宏观判断

### 11.1 不预测利率和短期市场

伯克希尔明确不预测下周、明年或未来几十年的利率和股市。分析中可以使用情景假设，但不要把结论建立在单一宏观预测上。

更可靠的问题是：

- 这部分企业所有权是否比市场价格更有价值？
- 企业长期回报是否显著高于低风险债券？
- 资产是否能抵御通胀并分享生产率增长？
- 公司是否能在多种利率、税率和经济环境中存活？

### 11.2 长期股票收益来自企业复利，不来自行情预测

2018年信的“美国顺风”和2019年信的留存收益共同表达一个原则：长期股权回报来自企业储蓄、再投资、生产率提升和制度环境，而不是每日价格波动。

对投资者的要求：

- 不使用杠杆买股票。
- 能承受50%甚至更大市场下跌。
- 控制情绪，不在恐慌中把临时波动变成永久损失。
- 降低费用，避免长期复利被顾问、交易和产品费吞噬。
- 不因赤字、政治、利率新闻或短期危机放弃对优质企业的长期所有权。

## 十二、风险分析

不要把风险等同波动。真正重要的是永久性资本损失。

风险输出必须覆盖：

| 风险 | 分析问题 |
| --- | --- |
| 会计风险 | 报表利润是否被未实现涨跌、调整口径、准备金、减值或资本化支出扭曲 |
| 资本结构风险 | 是否有短债、担保、可赎回负债、抵押品追缴或流动性错配 |
| 业务风险 | 护城河是否被成本、技术、监管、客户行为或替代品侵蚀 |
| 承保风险 | 损失估计是否可能多年后才暴露，巨灾是否威胁资本 |
| 资本配置风险 | 留存收益是否流向低回报项目、昂贵并购或高价回购 |
| 治理风险 | 董事会是否弱化，CEO 是否追求规模、薪酬、交易和短期数字 |
| 价格风险 | 好公司是否被买得太贵，导致长期回报不足 |
| 投资者行为风险 | 杠杆、恐慌、频繁交易和高费用是否会破坏长期复利 |

每个重大风险都要判断：发生概率、损失范围、暴露时间、公司适应能力、是否造成永久性损失。

## 分析流程

按以下顺序输出公司分析：

1. **结论先行**：给出买入、观察或回避判断，并说明核心理由和最大不确定性。
2. **会计还原**：拆分报告利润，剔除未实现投资波动，调整真实成本、维护资本开支、税率和非经常项。
3. **森林拆分**：按控股经营业务、股权投资、现金、债务、保险或类金融资金来源拆分价值。
4. **经营质量**：评估净有形资本回报、定价权、成本优势、增长空间、现金转化和资本需求。
5. **留存收益**：计算或定性判断历史留存收益的再投资回报，区分优秀复利与低效扩张。
6. **资本配置**：分析内部再投资、并购、回购、分红、发股、偿债和现金储备是否提高每股内在价值。
7. **保险或金融特征**：若适用，评估浮存金、承保纪律、信用质量、资产负债匹配和流动性。
8. **治理文化**：评估 CEO、董事会、继任机制、股东导向、会计诚实和反官僚能力。
9. **风险韧性**：判断极端场景下公司是否能生存、守住信用并趁机进攻。
10. **估值与安全边际**：给出内在价值区间、关键假设、当前价格隐含预期和需要的安全边际。

## 快速核查清单

- 是否把 GAAP 净利润当作真实经营成果？
- 是否把未实现投资涨跌和经营利润混在一起？
- 是否盲信调整后 EBITDA，而忽略股权激励、重组、折旧和维护资本开支？
- 是否把账面价值当作内在价值？
- 是否只看分红，忽略被投资公司的留存收益？
- 是否把股票投资当作代码组合，而不是企业部分所有权？
- 是否检验留存收益是否真的创造增量价值？
- 是否高估并购协同，低估买方容易做梦的风险？
- 是否检查回购价格是否低于内在价值，且回购后仍有充足现金？
- 是否低估债务在信用枯竭时的致命性？
- 是否把现金看成低效资产，而忽视其灾难韧性和机会价值？
- 是否检查董事是否业务导向、所有者导向，并用自己的钱持股？
- 是否识别管理层为了季度数字而操纵经营或会计的迹象？
- 是否把市场波动误认为风险，而忽略永久性资本损失？
- 是否在估值中扣除未来税负、债务、少数股东权益和其他真实负担？
- 是否因为宏观新闻、利率预测或短期恐慌，偏离对企业长期复利能力的判断？
