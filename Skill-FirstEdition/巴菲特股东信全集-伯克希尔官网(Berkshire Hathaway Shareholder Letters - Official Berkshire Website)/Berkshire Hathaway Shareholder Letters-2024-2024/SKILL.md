# 伯克希尔2024年股东信公司分析方法论

## 使用原则

把自己放在长期缺席股东的位置：如果你的家庭储蓄交给这家公司管理，而你不参与日常经营，你最需要知道什么？公司分析必须回答“你拥有什么、它怎样赚钱、谁在替你经营、资本怎样被配置、坏事会怎样发生、价格是否补偿风险”。

核心姿态：
- 把股票视为企业的部分所有权，不视为行情符号。
- 把年报视为管理层对所有者的受托报告，不只看合规披露。
- 同时寻找好消息和坏消息；管理层如果永远只讲顺风故事，要提高怀疑级别。
- 允许投资者和经理人犯错，但不允许拖延纠错。错误通常来自两类：误判业务未来经济性，误判经理人的能力或忠诚。
- 用经营利润和分部经济事实开始分析，不用受市场价格波动污染的净利润开始分析。
- 拒绝用 EBITDA 掩盖折旧、摊销、利息和税，这些都是经济成本。
- 永远把永久性资本损失放在股价波动之前。
- 偏爱能长期适应通胀和货币不稳定的生产性资产；现金和短债是安全垫与选择权，不是长期替代品。
- 记住少数重大赢家可以抵消许多平庸和错误决策；任务是识别并耐心持有真正会“开花”的业务。

一句话检验：如果未来十年没有市场报价，你是否仍愿意拥有这家公司，并依靠它的经营成果、资本配置和管理层行为来获得回报？

## 一、先写所有权地图

不要从市盈率开始。先拆清楚股东真正拥有的资产、业务和资金来源。

| 所有权单元 | 关键问题 | 核心证据 |
| --- | --- | --- |
| 控股经营业务 | 是否有持久需求、定价权、成本优势、优秀经理人和可持续税后经营利润 | 分部利润、现金转化、维护资本开支、增量资本回报、客户黏性 |
| 少数股权或上市股票 | 是否是高质量企业的一小部分所有权，而不是短期交易筹码 | 持股比例、应占利润、分红、回购价格、留存收益用途、管理层股东导向 |
| 保险或类保险资金来源 | 浮存金是否长期、低成本、稳定，并由承保纪律支撑 | 浮存金规模、承保利润、综合成本率、赔付久期、准备金充足性、巨灾承受力 |
| 现金和短期国债 | 是必要现金、机会现金，还是长期冗余现金 | 监管需求、债务到期、极端赔付、并购能力、市场错价机会、现金收益率 |
| 重资产基础设施 | 不可替代资产能否转化为合理股东回报 | 维护资本开支、折旧是否低估、监管契约、服务质量、增量投资回报 |
| 债务和币种结构 | 负债是否匹配资产期限、现金流和货币暴露 | 到期表、固定或浮动利率、担保关系、外币资产与外币债务匹配 |
| 综合企业或控股公司 | 总部是否能把留存收益配置到高回报处 | 子业务质量、资本配置历史、并购纪律、回购纪律、薪酬克制、股东沟通 |

输出时先写清楚：这家公司不是一个股票代码，而是一组业务、资产、负债、现金、经理人和资本配置选择的组合。

## 二、还原真实经营表现

### 2.1 区分经营利润和会计波动

分析利润时先拆分：
- 可持续经营利润：主营业务税后利润，优先分析。
- 保险承保利润：只在承保纪律真实存在时才有价值。
- 投资收入：可能真实且重要，但要区分利率周期、持仓规模和可持续性。
- 已实现投资收益：是真实收益，但发生时点不规则，不要机械年化。
- 未实现投资涨跌：反映市场报价变化，不等于当期经营表现。
- 外汇收益或损失：先判断是否来自会计折算，还是实际经济暴露。
- 一次性项目和减值：追问是长期盈利能力下滑，还是周期、诉讼、监管或会计确认。

不要只写“净利润增长”或“净利润下降”。必须解释哪些数字代表经营事实，哪些只是市场价格、外汇折算、利率变化或会计规则的表达。

### 2.2 用分部视角看质量

对多元公司逐个分部判断：
- 增长来自价格、销量、效率、承保改善、投资收入，还是一次性顺风？
- 利润增长是否需要大量新增资本？
- 折旧是否足以代表真实维护资本开支？
- 是否存在某些业务拖累整体，但被合并报表掩盖？
- 是否有少数业务贡献了绝大部分长期价值？

经营利润是起点，不是终点。最终要判断每个分部能否把利润转化为每股内在价值增长。

### 2.3 警惕 EBITDA 和调整后指标

在铁路、公用事业、制造、能源、通信、地产和其他重资产行业，折旧和维护资本开支是实实在在的经济成本。使用 EBITDA 时必须扣回：
- 真实维护资本开支。
- 利息成本和再融资风险。
- 税负。
- 股权稀释。
- 资产更新、监管要求、安全投入和环境责任。

如果管理层强调 EBITDA，却回避自由现金流、维护资本开支和折旧不足，要降低披露质量评分。

## 三、识别业务质量

优质企业不是短期利润高，而是能长期保持良好经济特征，并能把资本投入到合理或高回报机会中。

优先寻找：
- 产品或服务有长期必要性，而不是短期流行。
- 客户愿意反复购买，且转换成本、品牌、网络、规模、监管位置或成本曲线形成保护。
- 业务能适应通胀，长期提高名义收入和现金流。
- 公司不需要持续高杠杆才能维持增长。
- 单个重大成功决策有可能长期放大价值。
- 业务简单到足以理解关键变量，复杂处能被管理层清楚解释。

警惕：
- 把周期高点当作正常盈利。
- 把规模当作质量。
- 把账面资产当作内在价值。
- 把短期股价表现当作经营成果。
- 把漂亮叙事当作护城河。

## 四、评价经理人：能力、忠诚和纠错速度

2024年信把经理人评价放在很高位置。分析时分三层。

### 4.1 能力

检查：
- 是否真正理解业务关键变量，而不只是熟悉资本市场语言。
- 是否能在困难时期提高效率、保护客户、维护声誉。
- 是否能把资源投向高回报机会。
- 是否能调整落后业务，而不是用愿望替代行动。
- 是否有可验证的长期业绩，而不是只靠学历、头衔或简历光环。

不要用名校、咨询背景或媒体形象替代商业判断。许多优秀经营者的能力来自天赋、经验、专注和对业务的热爱。

### 4.2 忠诚和诚信

检查：
- 披露是否像对合伙人说话，坦率讲好事和坏事。
- 管理层是否承认错误，还是把错误包装成外部环境。
- 薪酬是否克制，并与长期股东结果同向。
- 是否用复杂指标、乐观话术和“调整后”数字遮盖成本。
- 是否在并购、回购、发股、分红和债务上公平对待现有股东。

能力不足会损失钱，诚信不足会损失钱和信任。与不可信的人合作，不要指望合同和制度能完全保护你。

### 4.3 纠错

重大错误不可避免，拖延纠错才是核心风险。分析时写清：
- 这家公司过去犯过什么资本配置错误？
- 管理层是否公开承认错误？
- 错误是否被及时止损、出售、减值、换人或重组？
- 是否存在为了面子、薪酬或规模继续投入坏项目的行为？
- 董事会是否有能力迫使管理层面对现实？

结论中要区分“可修正错误”和“永久性结构损害”。

## 五、资本配置顺序

按以下顺序评价管理层配置资本的能力。

### 5.1 内部再投资

第一选择是让已有优秀业务更强。检查：
- 增量资本回报是否高于资本成本。
- 资本开支是维护现状，还是创造新增盈利能力。
- 成长是否牺牲承保纪律、产品质量、客户信任或财务安全。
- 公司是否能在不依赖外部融资善意的情况下完成必要投资。

### 5.2 购买少数股权

公开市场的优势是偶尔能买到优秀企业的一小部分。检查：
- 买入的是好企业，还是便宜证券。
- 被投企业是否拥有高回报净有形资产、可信经理人和股东导向文化。
- 留存收益是否创造价值。
- 回购是否在低于内在价值时减少股份。
- 投资者是否能长期忍受没有控制权。

### 5.3 整体收购

收购时要同时评估价格、业务和人。检查：
- 卖方为什么愿意卖给这家公司，是只因价格，还是因为信任、文化和永久归宿。
- 收购价格是否不依赖夸大协同也合理。
- 原经理人是否愿意继续经营。
- 激励方案是否奖励增量利润，同时调整新增资本占用。
- 是否因控制权溢价、乐观预测或高估股票而支付过高价格。

整体收购的好处是能控制资本配置和经理人选择；坏处是买错后退出很难。公开股票买错时更容易改变路线，但无法控制管理层。

### 5.4 回购和分红

回购只有在两个条件同时满足时才创造价值：
1. 回购价格低于保守估计的内在价值。
2. 回购后公司仍保有足够现金、信用和极端情境承受力。

分红不是天然好或坏。若公司能把留存收益长期投向高回报机会，不分红可以创造巨大复利；若缺乏机会而继续留存，分红或回购可能更理性。

## 六、财产险和浮存金模块

财产险的特殊性在于：先收钱，许多年后才知道产品真实成本。使用本模块时先看承保，再看投资。

### 6.1 承保纪律

检查：
- 定价是否足以吸收巨灾、通胀、诉讼、欺诈和长尾赔付。
- 准备金是否保守，还是靠低估赔付制造虚假利润。
- 业务是否因价格不足而主动收缩。
- 承保人员是否保持谨慎，既紧张又不瘫痪。
- 公司是否愿意放弃不合格保费，而不是为了留在游戏里低价承保。

低价承保是企业自杀。不要把保费增长当作好消息，除非价格和风险匹配。

### 6.2 浮存金价值

高质量浮存金的特征：
- 长期稳定或增长。
- 成本低，理想情况下伴随承保利润。
- 流出节奏慢，不像短期存款那样容易集中挤兑。
- 公司有资本、现金和多元盈利承受极端损失。
- 投资端能理性使用浮存金，不被杠杆和收益率诱惑破坏。

估值时不要把浮存金简单当作债务，也不要免费视为权益。要估计成本、久期、稳定性、极端损失和可投资期限。

### 6.3 长尾风险

长尾险种可能多年报告虚假利润。必须检查：
- 赔付从事故到确认要多久。
- 通胀、医疗、法律和陪审团裁决是否提高最终成本。
- 公司是否有历史准备金释放或追加的记录。
- 管理层是保守、乐观，还是有激励低估损失。
- 巨灾、野火、风暴、产品责任和医疗责任是否可能集中发生。

## 七、现金、短债、货币和生产性资产

伯克希尔持有大量现金和短债，不代表偏爱现金胜过企业。原则是：永远不让公司在危机中依赖外部善意，同时等待罕见机会。

把现金分成三类：
- 必要现金：满足保险赔付、监管、营运、债务和极端事件。
- 机会现金：在市场冻结、并购或错价时立即行动。
- 冗余现金：长期没有用途，可能需要分红或回购。

不要因为现金收益率短期提高就把现金当作长期资产。纸币会受财政和货币纪律影响，固定息票债券不能保护购买力。长期价值主要来自生产性资产、优秀业务和人的特殊技能。

外币资产分析：
- 不预测汇率，把汇率作为情景变量。
- 尽量匹配外币资产与外币固定利率债务，降低净货币暴露。
- 区分会计外汇收益和真实经济收益。
- 比较外币资产分红收益与外币债务利息成本。
- 检查债务期限、利率类型和再融资风险。

## 八、日本商社式综合企业模块

分析综合商社或多元控股企业时，不要因为业务多就自动认为安全。重点是资本配置、股东态度和价格。

检查：
- 财务记录是否显示低估，而不是只靠故事吸引人。
- 管理层是否克制薪酬。
- 公司是否在合适时提高分红。
- 公司是否在价格合理时回购股份。
- 留存收益是否投向高回报业务，而不是帝国扩张。
- 管理层是否尊重长期股东，并愿意建立长期伙伴关系。
- 是否存在可理解的货币匹配策略。

多元化只有在资本配置者优秀时才是优势；否则只是难以看清的低回报组合。

## 九、重资产、铁路和公用事业模块

重资产业务可能不可替代，也可能吞噬现金。必须把资产重要性和股东回报分开。

检查：
- 资产是否对客户、国家或产业链不可替代。
- 维护资本开支是否长期高于折旧。
- 服务质量、安全和可靠性是否需要持续投资。
- 监管框架是否允许合理回报。
- 极端天气、野火、诉讼和政治环境是否改变资产价值。
- 公司是否有能力在不牺牲财务韧性的情况下完成长期项目。

在公用事业中，历史稳定不等于未来稳定。监管、司法和气候风险可能改写经济契约。

## 十、风险定义：永久性资本损失

不要把风险等同于波动。真正风险是资本永久受损、信用崩塌、竞争地位丧失、文化腐蚀、监管契约破裂、承保纪律失控、高价买入后的长期低回报。

| 风险 | 分析问题 |
| --- | --- |
| 业务误判 | 未来经济性是否被高估，需求、成本或竞争是否永久恶化 |
| 人员误判 | 经理人是否能力不足、不诚信，或董事会拖延换人 |
| 会计风险 | 利润是否被未实现涨跌、外汇、准备金、资本化费用或调整后指标扭曲 |
| 承保风险 | 长尾赔付、巨灾、诉讼和欺诈是否可能吞噬多年利润 |
| 价格风险 | 是否用好公司故事支付了过高价格 |
| 流动性风险 | 是否依赖短债、外部融资、再保险或资本市场持续开放 |
| 监管风险 | 公用事业、铁路、金融、能源或资源资产的制度契约是否会改变 |
| 货币风险 | 现金、债券或外币资产是否暴露于购买力和汇率损失 |
| 资本配置风险 | 留存收益是否流向低回报扩张、昂贵并购或高价回购 |
| 行为风险 | 投资者是否因恐慌、杠杆、频繁交易和费用破坏复利 |

每个重大风险都写出：发生概率、损失范围、暴露时间、公司适应能力、是否会导致永久性损失。

## 十一、估值和安全边际

估值不是给一个精确数字，而是形成保守区间。

步骤：
1. 估算正常化经营利润和维护后自由现金流。
2. 对少数股权估算应占经济利润、分红和留存收益价值。
3. 对保险浮存金估算成本、久期、稳定性和极端损失。
4. 对重资产业务扣除真实维护资本开支，并评估监管回报。
5. 对现金和短债区分必要现金、机会现金和冗余现金。
6. 扣除债务、税负、少数股权、养老金、诉讼、环境责任和潜在巨灾。
7. 对利率、汇率、灾害、商品价格、监管和周期做情景测试。
8. 要求足够安全边际，尤其当业务复杂、经理人不确定或资本需求不清晰时。

结论必须说明当前价格隐含了什么预期：高增长、稳定利润率、低赔付、好监管、低利率、成功并购，还是已经反映悲观情景。

## 输出流程

按以下顺序输出公司分析：

1. **结论先行**：给出买入、观察或回避判断，说明核心理由、最大不确定性和所需安全边际。
2. **所有权地图**：列出公司真正拥有的业务、股权、现金、债务、浮存金、重资产和特殊资金来源。
3. **经营表现还原**：拆分经营利润、投资收入、未实现涨跌、外汇、一次性项目、真实维护资本开支和应占经济利润。
4. **业务质量**：判断持久需求、定价权、成本优势、客户黏性、增量资本回报和十年后可预测性。
5. **经理人与文化**：评价能力、忠诚、薪酬克制、错误承认、纠错速度、披露质量和股东导向。
6. **资本配置**：分析内部再投资、少数股权投资、并购、回购、分红、现金和债务是否提高每股内在价值。
7. **特殊模块**：按需加入财产险浮存金、重资产、公用事业、综合商社、外币资产和货币匹配分析。
8. **财务韧性**：测试衰退、信用冻结、巨灾、诉讼、利率变化、汇率变化、监管变化和市场关闭。
9. **估值区间**：给出保守内在价值区间、关键假设、当前价格隐含预期和重新评估触发点。
10. **最终判断**：说明是否值得长期持有，以及未来最该跟踪的三件事。

## 快速检查清单

- 是否把股票当作企业所有权，而不是交易符号？
- 是否像缺席股东一样追问“我真正拥有什么”？
- 是否同时写出好消息和坏消息？
- 是否拆分经营利润、投资收入、未实现涨跌、外汇和一次性项目？
- 是否拒绝用 EBITDA 替代真实维护后现金流？
- 是否检查管理层承认错误和纠错速度？
- 是否评价经理人的能力、忠诚和薪酬克制，而不是只看学历和头衔？
- 是否区分公开市场少数股权和整体收购的优缺点？
- 是否分析资本配置是否提高每股内在价值？
- 是否把现金分为必要现金、机会现金和冗余现金？
- 是否确认现金不是长期替代好企业的资产？
- 是否在保险公司中先看承保纪律，再看投资收益？
- 是否估算浮存金成本、久期、稳定性和极端损失？
- 是否警惕长尾赔付、乐观准备金和巨灾风险？
- 是否在价格不足时要求公司愿意收缩业务？
- 是否区分重资产不可替代性和真实股东回报？
- 是否评估监管契约、气候、诉讼和政治风险？
- 是否对外币资产做货币匹配，而不是预测汇率？
- 是否判断多元企业的资本配置者是否优秀？
- 是否把风险定义为永久性资本损失，而不是股价波动？
- 是否给出保守估值区间和安全边际？
