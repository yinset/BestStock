# 巴菲特企业分析方法论（2012-2013股东信精华）

## 一、核心价值观：以内在价值为锚

### 1.1 内在价值 vs. 账面价值
- **账面价值是代理指标，不是目标本身。** 内在价值始终大幅超过账面价值，差距随时间扩大。
- 两个量化追踪维度（缺一不可）：
  - 每股投资额（含股票+债券）
  - 每股税前经营利润（不含保险和投资）
- 这两项指标的长期复合增速（约19-21%）与股价涨幅高度一致——这不是巧合，而是规律。
- **会计账面价值的常见失真**：GAAP要求将浮存金（float）全额计为负债，但只要浮存金持续且低成本，其真实负债价值远小于账面值。购买溢价形成的商誉也常被低估。

### 1.2 每股价值优于总规模
- 衡量成功的标准永远是**每股内在价值增长**，而非总资产或总收入增长。
- 收购支付对价时，若大量增发股票，即使账面做大了，每股价值可能实际被稀释。
- 判断标准：过去近十年"五大引擎"（BNSF、MidAmerican、Iscar、Lubrizol、Marmon）带来税前利润增加104亿美元，股份稀释仅6.1%——这才叫真正的增值。

## 二、业务分类框架：四大板块独立审视

巴菲特明确拒绝把所有业务混为一谈，因为不同板块的**资产负债表结构和盈利特征截然不同**：

| 板块 | 核心逻辑 | 关键指标 |
|------|---------|---------|
| **保险** | 浮存金驱动，承保盈利为加分项 | 浮存金规模、承保利润/亏损、综合比率 |
| **受监管资本密集型**（铁路、能源）| 长生命周期资产，稳定现金流，受益于长期基础设施需求 | 利息覆盖倍数（税前利润/利息，而非EBITDA）、资本支出/折旧比 |
| **制造/服务/零售** | 轻资产优先，用无杠杆净有形资产回报率衡量经济特性 | 税后RONTA（目标：优质业务25%-100%+，良好12%-20%）|
| **投资组合（股票）**| 部分所有权，留存收益同样属于伯克希尔 | 应占利润（含未分配）、长期复利潜力 |

**操作要点**：分析任何多元化企业时，先做板块拆分，再分别评估，最后合并估值。

## 三、保险业务的独特分析框架

### 3.1 浮存金（Float）：真正的护城河
- **定义**：先收保费、后赔付，形成可自由投资的他人资金。
- **价值判断三要素**：
  1. 规模能否持续增长或至少稳定？
  2. 成本是否为零甚至为负（即承保盈利）？
  3. 是否具有长期性（不会突然大规模提取）？
- 伯克希尔浮存金从1970年3900万美元增至2013年772亿美元，期间连续11年承保盈利，税前累计盈利220亿美元——这意味着这笔钱不仅免费，还被人付钱来持有。
- **行业对比视角**：全行业大多数年份承保亏损，浮存金有成本；伯克希尔的低成本浮存金是真正稀缺的竞争优势。

### 3.2 承保纪律高于规模扩张
- 扩大市场份额（如GEICO从2.5%到9.7%）必须在**不牺牲承保纪律**的前提下实现。
- 即使面临大灾损失（如行业损失2500亿美元的极端情景），伯克希尔整体仍应保持盈利——这是资本实力与多元收益流的体现。

## 四、收购哲学：大象猎手 + 补强并购双轨制

### 4.1 大型收购（"猎象"）标准
- 可独立运营、有稳定盈利历史（不接受"未来潜力"的故事）
- 经济特性良好，股东权益回报率合理
- 管理层到位，无需总部深度介入
- 公平定价（无须特价，但不能过贵）
- 不偏好需要大量资本、高技术含量或危机转型类企业
- **永久持有**，不打算出售（这与私募股权本质不同）

### 4.2 补强收购（Bolt-on）：低风险的价值累积
- 并入现有业务，由原有管理团队运营，总部零负担
- 2012年完成26项，合计约23亿美元；2013年合计31亿美元，25项
- 判断标准：是否能增强现有业务护城河？是否无须发行股票？
- 这类收购是"风险低、负担轻、价值可见"的理想增量。

### 4.3 估值支付原则
- 优质企业愿意支付溢价，但拒绝用股票支付（稀释每股价值）
- 警惕：以净有形资产溢价大幅收购，意味着商誉大、摊销高——需识别"非真实摊销"
- 宁可以公道价买优质企业，不以廉价买平庸企业（Charlie Munger原则）

## 五、会计读法：区分经济现实与GAAP数字

### 5.1 摊销费用的两种性质
- **真实摊销**（如软件、有限寿命资产）：确实是成本，应计入。
- **非真实摊销**（如客户关系摊销、核心存款摊销）：购买会计规则产物，非真实经济成本，应加回。
- 伯克希尔制造/服务/零售板块：约80%的无形资产摊销费用（约5-6亿美元）属于非真实摊销，应加回后再判断真实盈利能力。

### 5.2 EBITDA的谬误
- **折旧是真实成本**，反映资产消耗；EBITDA加回折旧会高估实际盈利。
- 资本密集型企业（铁路、能源）尤其如此：BNSF资本支出约为折旧的2倍，说明折旧严重低估了维持竞争力所需的真实投资。
- **正确利息覆盖率**= 税前利润/利息，而非EBITDA/利息。

### 5.3 浮存金的账面失真
- GAAP将浮存金全额列为负债，但若浮存金长期稳定且成本为零，其真实负债价值远低于账面——这导致账面净资产系统性低估内在价值。

## 六、资本配置优先级

按巴菲特明确陈述的顺序：

1. **提升现有子公司盈利能力**（有机增长）
2. **补强收购**（无须发行股份）
3. **参与投资组合公司的成长**（持有优质股票的留存收益）
4. **在折价时回购自身股票**（当股价低于内在价值120%时积极回购）
5. **偶发性大型收购**

**铁律**：几乎从不增发股票。股票是宝贵的货币，稀释现有股东是最坏的资本配置。

## 七、管理层评估标准

### 7.1 股东导向的管理者特征
- 视公司为家族唯一资产般运营
- 多数人没有财务上的工作必要性，靠打"商业本垒打"的乐趣驱动
- 不以规模、员工数量、收入为KPI，以每股内在价值增长为KPI

### 7.2 总部极简原则
- 伯克希尔总部：仅24人管理2800亿美元资产
- 判断标准：总部是否"零负担"？管理层是否充分授权？

### 7.3 接班人与人才储备
- 投资经理（Todd Combs、Ted Weschler）：连续跑赢S&P 500，且具有"伯克希尔血液"（文化契合）
- 接班人标准：能在无监督情况下做出同等决策，且不偏离价值观

## 八、长期视角与宏观判断

### 8.1 永远不要对美国经济做空
- 过去237年押注美国繁荣几乎从未错过；动态的市场经济仍是最强复利机器。
- 宏观"不确定性"是永恒存在的，但不应成为不行动的借口。
- 退出市场的风险远大于留在市场的风险。

### 8.2 市场周期中的相对表现规律
- 市场强势年（S&P涨幅>15%）：伯克希尔大概率跑输；
- 市场下跌或平淡年：伯克希尔大概率跑赢；
- 判断周期：用完整市场周期（如2007-2013）而非单年来评估长期表现。

### 8.3 基础设施与能源的长期逻辑
- 社会对运输（铁路）和能源的需求是永久性的；
- 政府有自我利益去善待基础设施资本提供者；
- 因此，虽然受监管，但回报可预期，值得大规模长期资本投入。

## 九、使用本方法论的分析步骤

分析一家公司时，按以下顺序思考：

1. **定性识别**：这家公司属于哪个业务类别？护城河的来源是什么（成本优势、品牌、网络效应、监管壁垒、切换成本）？
2. **量化估值**：用每股投资额 + 每股经营利润两条线追踪内在价值走势，不依赖单一P/E倍数。
3. **会计调整**：剔除非真实摊销，折旧不加回，用税前利润/利息而非EBITDA覆盖率。
4. **资本配置**：管理层过去如何分配资本？是否增发稀释？回购时机是否合理？
5. **管理层质量**：是否具备股东导向？总部是否精简高效？
6. **价格纪律**：支付价格是否合理？是否用股票支付（扣分）？
7. **长期判断**：百年后这家公司是否仍将存在且不可或缺？

## 附：关键指标速查

| 指标 | 巴菲特的偏好/标准 |
|------|----------------|
| 内在价值增速 | 长期超越S&P 500（哪怕微弱） |
| 无杠杆净有形资产税后回报率 | 优质：25%-100%+ / 良好：12%-20% |
| 保险综合比率 | <100%（承保盈利） |
| 利息覆盖倍数 | 税前利润/利息（>5x 为健康；BNSF目标~9x）|
| 资本支出/折旧比 | >1（资本密集型成长业务正常，需理解原因） |
| 股份增发 | 接近零为最优；每次增发必须带来相应价值 |
| 总部员工人数 | 极少（伯克希尔标准：24人管理千亿级资产）|
