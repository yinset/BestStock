# 伯克希尔公司分析方法论（2020-2021股东信精华）

## 使用原则

把自己放在缺席股东的位置：如果你是企业所有者，而管理层替你经营，你最想知道什么？分析时直接回答这些问题，而不是围绕股价、市场情绪或短期预测展开。

核心姿态：
- 把股票当作企业部分所有权，不当作交易符号。
- 重点分析长期经营表现，不预测短期市场走势。
- 以每股内在价值增长为最终目标，而不是以规模、收入、GAAP净利润或股价表现为目标。
- 先看企业质量、管理层和价格，再看叙事。
- 允许自己承认错误，尤其区分“买错价格”和“买错企业”。
- 用长期股东、债权人、保险索赔人和经营伙伴都能安睡的标准衡量财务安全。

分析必须围绕六个根问题：
1. 这家公司真实拥有的是什么企业、资产和资本来源？
2. 这些企业是否有持久经济优势，并由一流管理者经营？
3. 报表数字中哪些是真实经营成果，哪些只是会计波动或暂时噪音？
4. 留存收益、现金、债务和回购是否提高每股内在价值？
5. 公司能否在灾难、衰退、低利率、监管变化或资本市场关闭时生存并进攻？
6. 当前价格是否低于保守估计的内在价值，并留有安全边际？

## 一、先说明“你真正拥有的是什么”

分析复杂公司时，不要从一个市盈率开始。先把公司拆成可理解的所有权单元：

| 所有权单元 | 核心判断 | 重点证据 |
| --- | --- | --- |
| 控股经营业务 | 是否能长期扩大税后经营盈利 | 正常化经营利润、增量资本回报、维护性资本开支、定价权、现金转化 |
| 非控股上市股权 | 是否是一组优秀企业的部分所有权 | 应占盈利、分红、留存收益用途、回购、杠杆、税后潜在价值 |
| 权益法或合营投资 | 账面价值是否偏离经济价值 | 应占利润、市场价值、控制权限制、退出条件、减值风险 |
| 保险或类保险资金 | 浮存金是否长期、低成本、可投资 | 浮存金规模、承保利润、综合成本率、赔付久期、巨灾压力 |
| 现金和短债 | 是战略储备还是低收益拖累 | 必需现金、机会现金、冗余现金、流动性、机会成本 |
| 重资产基础设施 | 资本开支是否能换来合理增量回报 | 固定资产规模、监管机制、折旧与资本开支、服务质量、长期需求 |

输出时先写清楚：这家公司不是一个股票代码，而是一组企业、资产、负债、现金和管理制度的组合。

## 二、清除会计噪音

### 2.1 区分经营利润和GAAP波动

伯克希尔2020年GAAP盈利包含经营盈利、已实现资本利得、未实现投资涨跌和减值。真正需要优先分析的是可持续经营盈利，以及这些盈利能否转化为每股内在价值。

分析时拆分：
- 经营盈利：主业税后盈利，优先关注。
- 已实现投资收益：可能真实，但时间不规则，不能机械年化。
- 未实现投资涨跌：反映市场价格波动，不等于当期经营表现。
- 减值和一次性损益：必须追问是价格错误、盈利能力永久下降，还是周期性冲击。
- 权益法和少数股权：注意账面价值、市场价值和经济价值可能不同。

不要只写“净利润增长”或“净利润下降”。必须解释净利润中哪些代表经营事实，哪些只是会计表达。

### 2.2 看穿未记录的留存收益

非控股股权投资的报表收入通常只确认分红，但被投资公司留存的利润仍然属于股东经济利益的一部分。分析股权投资或持有大量股权资产的公司时，要估算“应占经济盈利”：

```text
应占经济盈利 = 收到的分红 + 持股比例对应的被投资公司留存收益
```

然后判断留存收益是否被有效使用：
- 扩大高回报业务。
- 做理性补强收购。
- 偿还高成本债务。
- 在低估时回购股份。
- 或被低回报扩张、昂贵并购、库存、应收账款和官僚体系吞掉。

### 2.3 正常化盈利，不正常化幻想

Precision Castparts 的教训是：优秀企业也可能买贵。错误不在于业务一定差，而在于高估了正常化盈利能力，并据此支付了过高价格。

分析收购或估值时：
- 估算中周期盈利，不拿景气峰值当常态。
- 分拆行业周期、客户集中、价格、产能利用率和资本需求。
- 检查管理层是否坦率承认资本配置错误。
- 区分“好公司、坏价格”和“坏公司、低价格”。
- 对需要多年恢复的利润假设打折。

## 三、做“business-picker”，不是“stock-picker”

伯克希尔2021年信的核心句是：不是选股票，而是选企业。使用此 skill 时必须从企业角度判断，而不是从行情角度判断。

优质企业标准：
1. 有持久经济优势。
2. 有一流CEO和可信文化。
3. 长期业务表现可大致判断。
4. 能把留存收益或增量资本投到合理回报上。
5. 价格相对内在价值合理。

普通股票市场的优势在于，偶尔能用好价格买到优秀企业的一小部分，而且犯错后退出更容易。谈判式整体收购很少出现“优秀企业大面积便宜”的机会，且通常要付控制权溢价。

分析时回答：
- 这家公司十年后是否大概率仍有客户、利润和竞争地位？
- 护城河来自品牌、网络、成本、规模、监管位置、客户习惯、数据、文化，还是暂时景气？
- 管理层是否把客户、产品和长期声誉放在短期数字前面？
- 如果不能控制公司，是否仍愿意长期拥有它的一部分？

## 四、资本配置的三条路径

2021年信把价值创造分成三条路径。分析任何公司时都按这个顺序检查。

### 4.1 提高控股业务的长期盈利能力

第一选择永远是让已有业务更强：内部增长、效率提升、产品改善、补强收购和必要资本开支。

检查：
- 内部再投资回报是否高于外部收购？
- 增量资本是用于维护竞争力，还是创造新增盈利能力？
- 增长是否牺牲价格、信用质量、服务质量或长期声誉？
- 业务是否能随经济增长和通胀扩大名义收入？
- 公司是否清楚区分维护性资本开支和成长性资本开支？

### 4.2 买入优秀企业的非控股权益

当公开市场给出好价格时，买入优秀企业的部分所有权可能优于整体收购。

检查：
- 买入标的是否有持久经济优势和好管理层？
- 买入价格是否提供长期回报空间？
- 被投资公司留存收益是否创造价值？
- 回购是否提高持股比例和应占盈利？
- 税负和流动性是否已在估值中反映？

### 4.3 低估时回购自己

回购只有在两个条件同时满足时才创造价值：
1. 回购价格低于保守估计的内在价值。
2. 回购后公司仍保有充足现金和韧性。

分析回购时不要只看金额，必须看每股价值：
- 股份数是否真正下降，而不是仅抵消股权激励。
- 回购是否价格敏感，还是越涨越买。
- 回购是否挤占高回报内部投资、偿债能力或安全现金。
- 回购是否让持续股东拥有更多优质资产、更多应占盈利和更多浮存金。
- 卖出股东和留下股东是否都得到公平信息。

## 五、浮存金、现金和财务堡垒

### 5.1 浮存金是一种特殊资金来源

保险浮存金是“不是自己的钱，但可以投资的钱”。它不是普通债务，价值取决于期限、成本、稳定性和承保纪律。

高质量浮存金特征：
- 规模长期稳定或增长。
- 成本低，最好长期伴随承保利润。
- 流出缓慢，不像银行存款那样容易被集中挤兑。
- 赔付久期较长，能支持长期投资。
- 公司有资本、现金和多元盈利承受巨灾。

分析保险公司或类似资金来源时，先看承保纪律，再看投资收益。若靠低估损失、追逐差债、加杠杆或牺牲流动性提高收益，浮存金会从优势变成风险。

### 5.2 现金不是懒惰，而是生存权和选择权

伯克希尔承诺持有超过300亿美元现金及等价物，2021年持有大量短期国债。原因不是不喜欢企业所有权，而是在缺少合适机会时保持财务不可摧毁。

分析现金时分三类：
- 必需现金：满足监管、信用、营运、保险赔付和极端事件。
- 机会现金：在恐慌、并购或市场错价时能快速行动。
- 冗余现金：长期没有用途，可能需要分红或回购。

不要因为现金收益低就自动扣分。要问：这笔现金是否保护了企业不依赖外部善意，并使公司在危机中拥有选择权？

### 5.3 债务要放在能承受它的地方

好公司不该为了多一点回报而冒失去生存权的风险。分析债务时：
- 债务是否由能承受的子公司独立承担？
- 母公司是否提供担保？
- 是否有短债、抵押品追缴、可赎回债务、表外承诺或衍生品压力？
- 利息覆盖用真实经营利润衡量，不用粉饰后的EBITDA。
- 衰退、巨灾或资本市场关闭时是否仍能履约？

## 六、重资产也可以优秀，但必须有合理增量回报

资产轻、高利润率、低增量资本需求的业务通常最理想。但重资产业务也可以成为好投资，前提是长期需求稳定，监管或市场机制允许合理回报，管理层能持续执行。

BNSF和BHE给出的分析框架：
- 固定资产规模本身不是投资成功，增量资本回报才是。
- 铁路、能源、电网等基础设施需要几十年资本开支，必须看长期服务需求和监管结构。
- 资本开支先满足安全、可靠性和服务质量，再谈分红。
- 不分红不一定差，若全部盈利能投入高确定性项目并获得合理回报，留存更有价值。
- ESG叙事不能替代长期实际投资记录、项目进度、资本成本和回报机制。

分析重资产公司时输出：
- 维护性资本开支与成长性资本开支的区分。
- 折旧是否低估真实维护需求。
- 增量资本回报是否可接受。
- 监管、司法、政治和土地使用风险。
- 资产是否对国家、客户或产业链具有不可替代性。

## 七、并购：永久之家比最高报价更稀缺

2021年TTI案例说明，优秀创始人不只关心价格，也关心员工、文化、城市、客户和企业未来归宿。伯克希尔的优势来自“永久持有、少干预、讲信用”。

分析并购或潜在收购方时：
- 卖方为什么愿意卖给它？只是价格，还是信任？
- 是否依赖夸大的协同效应、裁员和搬迁来证明价格？
- 是否是金融买家，天然带有退出压力？
- 收购后是否保留优秀经理人、文化和运营自治？
- 买方是否在一个会议、一个午餐后也能判断业务，因为长期声誉让交易成本降低？
- 董事会是否知道最高可付价格，并能拒绝超过价值的交易？

收购能力不是“买很多”，而是以合理价格吸引好企业进入长期合适的家。

## 八、管理层、文化和股东类型

### 8.1 把股东当合伙人

伯克希尔强调平等沟通，不私下迎合分析师或大机构。公司应该告诉股东：如果你是缺席所有者，我作为经理人会告诉你什么？

检查：
- 信息披露是否直接、坦率、可理解？
- 是否承认错误和不确定性？
- 是否用周六发布等方式给所有股东公平吸收信息的时间？
- 是否避免为了市场预期管理短期数字？
- 是否吸引长期股东，而不是主动制造投机客群？

股东基础会反过来影响资本配置。长期股东少换手，可能减少低价回购机会，却更有利于企业长期建设。

### 8.2 一流CEO和可信经理人

优秀经理人的特征：
- 热爱业务，而不是只追求薪酬、名望或退出。
- 能把客户和产品放在第一位，同时让其他利益相关方受益。
- 在困难时期控制成本、保持服务和长期投资。
- 不需要总部天天干预。
- 对薪酬和地位不过度敏感。
- 与股东利益同向，愿意长期经营。

警惕：
- 频繁讲故事，却回避单位经济和资本回报。
- 追求规模、交易和短期市场掌声。
- 用“调整后”口径掩盖真实成本。
- 把并购协同建立在破坏文化和员工承诺上。

### 8.3 舒服的长期持有本身有价值

2021年信强调，能让股东安心长期持有的公司，会帮助股东避免被新闻、承诺和情绪驱动。分析时加入“行为适配性”：
- 投资者是否能忍受这家公司长期不被市场关注？
- 公司是否清楚自己服务哪类股东？
- 管理层是否持续提供一致的经营风格？
- 企业是否足够透明，使长期股东不必频繁交易？

## 九、宏观和利率只作为背景，不作为核心结论

低长期利率会推高所有生产性资产价格，包括股票、农场、公寓和油井。因此估值时必须承认利率影响。但不要把结论建立在单一宏观预测上。

正确做法：
- 用多种利率和经济情景测试估值。
- 观察公司是否能在通胀、低利率、衰退和信用收缩中生存。
- 判断资产是否能分享长期生产率增长。
- 不因宏观恐慌放弃对优秀企业长期复利能力的判断。
- 不因现金很多就断言管理层无能，先看是否缺少合适价格的机会。

## 十、风险：重点是永久性资本损失

不要把风险等同于股价波动。真正风险是永久性资本损失、信用崩塌、竞争地位丧失、文化腐蚀和高价买入后的长期低回报。

| 风险 | 分析问题 |
| --- | --- |
| 会计风险 | GAAP利润是否被未实现涨跌、减值、调整口径、资本化支出或准备金扭曲 |
| 价格风险 | 是否把优秀企业买得过贵，导致长期回报不足 |
| 盈利正常化风险 | 是否把周期高点、疫情特殊需求或一次性利润当作常态 |
| 资本配置风险 | 留存收益是否流向低回报项目、昂贵并购或高价回购 |
| 浮存金风险 | 承保是否纪律松动，巨灾或长尾赔付是否威胁资本 |
| 流动性风险 | 公司是否依赖外部融资、短债续作或资本市场善意 |
| 重资产风险 | 资本开支是否长期吞噬现金却得不到合理回报 |
| 治理风险 | CEO和董事会是否追求规模、薪酬、交易或短期数字 |
| 文化风险 | 公司是否丧失客户第一、员工信任、低官僚和长期主义 |
| 投资者行为风险 | 杠杆、恐慌、频繁交易和费用是否破坏复利 |

每个重大风险都要写出：发生概率、损失范围、暴露时间、公司适应能力、是否导致永久性损失。

## 分析流程

按以下顺序输出公司分析：

1. **结论先行**：给出买入、观察或回避判断，并说明核心理由、最大不确定性和需要的安全边际。
2. **所有权地图**：列出公司真正拥有的业务、股权、现金、债务、浮存金、重资产和特殊资金来源。
3. **会计还原**：拆分经营盈利、未实现投资涨跌、权益法、减值、一次性项目和真实维护资本开支。
4. **业务质量**：判断持久经济优势、客户黏性、定价权、成本优势、长期需求和资本需求。
5. **管理层和文化**：评估CEO、董事会、披露质量、错误承认、股东导向、员工和客户承诺。
6. **资本配置**：按三条路径分析内部再投资、外部股权投资、并购、回购、分红、现金和偿债。
7. **浮存金或金融特征**：若适用，分析浮存金成本、稳定性、承保纪律、资产负债匹配和巨灾压力。

9. **风险韧性**：测试衰退、利率变化、信用冻结、巨灾、客户流失、监管变化和管理层失误。
10. **估值和安全边际**：给出内在价值区间、关键假设、当前价格隐含预期和重新评估触发点。

## 快速检查清单

- 是否把股票当成企业所有权，而不是行情载体？
- 是否说明这家公司真正拥有的业务和资产？
- 是否拆分GAAP净利润和真实经营盈利？
- 是否估算被投资公司未分配留存收益的经济意义？
- 是否检查每一元留存收益的再投资回报？
- 是否区分好公司买贵和坏公司便宜？
- 是否识别资产轻业务和重资产业务的不同资本需求？
- 是否检验重资产项目的增量资本回报？
- 是否把现金分为必需现金、机会现金和冗余现金？
- 是否把浮存金当作有成本、有期限、有风险的特殊资金来源？
- 是否分析承保纪律，而不是只看投资收益？
- 是否按三条路径分析资本配置？
- 是否要求回购价格低于内在价值并保留韧性？
- 是否警惕用高估股票、协同故事或控制权溢价做并购？
- 是否评估公司能否成为优秀企业的永久之家？
- 是否判断CEO是否一流、坦率、热爱业务并长期导向？
- 是否检查披露是否平等面对所有股东？
- 是否把风险定义为永久性资本损失，而不是波动？
