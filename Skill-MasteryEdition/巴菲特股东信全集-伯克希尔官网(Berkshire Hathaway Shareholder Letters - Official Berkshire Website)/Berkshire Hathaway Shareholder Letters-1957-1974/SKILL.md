# 巴菲特公司分析 1957-1974：求同存异版

## 核心姿态

把股票当作企业所有权、企业事件权利或潜在控制权来分析。不要用市场预测替代企业判断；先问是否理解生意和事实，再问真实价值、价值释放路径、永久损失风险，以及这笔资本相对替代机会是否值得。

把1957-1974年方法压缩成一句话：在能力圈内，以保守价值和真实盈利为锚，用足够安全边际买入价格错误、资本回报可靠、管理层可信或价值可释放的机会，并用长期相对结果和税后机会成本检验自己。

需要追溯年份差异或来源时，读取 `references/year-differences.md` 和 `references/source-map.md`。

## 求同：共同底座

1. 能力圈先行
   - 写清楚公司如何赚钱、关键资产和负债是什么、哪些事实已知、哪些仍是推断。
   - 对不理解的业务、合同、会计、监管、技术、金融工程或风险暴露，直接标为“无法判断”。
   - 不要用乐观假设填补未知部分；资料不足时，结论应是资料不足或观察。

2. 机会必须分类
   - `普通低估/私人所有者价值`：价格低于理性买家愿为整个企业支付的保守价值。
   - `相对低估`：与同质量、同周期、同资本结构的可比公司相比显著便宜。
   - `Workout/特殊情形`：收益来自已公开宣布的并购、清算、重组、分拆、要约或类似公司行动。
   - `控股/资产转换`：通过大比例持股、控制权、董事会影响或经营改善释放价值。
   - `经营型长期持有`：重点看真实盈利、资本回报、管理层、财务强度和再投资能力。
   - 混合机会要拆开写；不要把普通便宜股伪装成确定性事件，也不要把相对便宜误写成私人所有者价值。

3. 估值必须保守
   - 用区间而不是单点。只有当前价格明显低于保守区间下沿，才称得上安全边际。
   - 按机会类型选择估值入口：正常化盈利、私人所有者价值、可出售资产、清算价值、营运资本释放、投资组合、浮存金价值、事件成功收益和失败损失。
   - 区分账面利润、市场报价和经济价值。报价能改变收益时间表，不等于改变内在价值。

4. 风险是永久性本金损失
   - 把短期报价波动与永久损失分开。
   - 检查价值毁灭路径：业务长期恶化、资产无法变现、杠杆压垮、管理层误配资本、事件失败、税务吞噬、会计误导、准备金不足、合同条款不利、价格纪律丧失。
   - 上涨时赚钱不能证明保守；下跌、低迷或坏年份更能检验方法和企业质量。

5. 管理层和资本配置是价值能否实现的核心
   - 看经营者是否诚实、能干、懂业务、愿意像所有者一样行动。
   - 检查董事、管理层、控股股东和资本提供者的利益是否一致。
   - 区分经营能力和资本配置能力。好业务可能被坏配置拖累，差行业也可能吞噬好管理层的努力。

6. 机会成本决定行动
   - 新机会必须打败现有最强机会和现金的替代用途。
   - 比较要用税后、费用后、交易成本后、风险调整后的预期收益，而不是名义收益。
   - 不因不愿交税、想回本、去年涨得好、市场预测或持仓惯性而持有次优资产。

## 存异：按问题选择年份镜头

1. 1957-1960镜头：低估、隐藏资产、保密建仓和主动价值释放
   - 适合分析资产折价、负估值经营业务、沉闷小盘、董事会激励错位、股东联盟、投资组合拆分。
   - 重点问：折价是否真实，防守性是否强，价值是否继续累积，是否存在可等待或可创造的释放路径。

2. 1961-1964镜头：类别化、标尺、Workout、控股和税后复利
   - 适合分析普通低估、相对低估、公开宣布的特殊情形、从普通股买成控制权、资产转换。
   - 重点问：机会类别是否清楚，金额、时间、失败概率和资金占用是否分开估算，事先标尺是否合理，税后复利是否优于替代机会。

3. 1965-1968镜头：能力圈、定性与定量、集中仓位和长期持有
   - 适合分析高确定性机会、控股收购、管理层质量、机会稀缺、是否该集中或等待。
   - 重点问：好价格和好生意是否同时存在，是否因为理解不足而风格漂移，集中是否来自高确定性而不是自信过度。

4. 1969-1974镜头：真实盈利、资本回报、财务强度和经营业务
   - 适合分析保险、银行、制造、零售、多元控股公司、周期低迷、库存、准备金、利率、浮存金和资本再部署。
   - 重点问：利润增长是否超过资本基数增长，规模是否有价格纪律，财务强度是否能支撑等待和逆周期扩张。

## 分析工作流

1. 定义问题和标尺
   - 说明用户要判断的是买入、持有、卖出、回避、仓位、收购、事件套利还是管理层评价。
   - 选定比较标尺：指数、现金、债券、现有持仓、同业公司、私人收购价值或其他可投资替代方案。
   - 评估期至少三年，最好覆盖强市、弱市和横盘；单年表现只作线索，不作判决。

2. 分类机会
   - 明确属于普通低估、相对低估、Workout、控股/资产转换、经营型长期持有，或混合。
   - 对混合机会分别列出收益来源、风险来源、时间表和退出条件。

3. 建立事实边界
   - 列出公司业务、客户、供应商、竞争者、监管、周期性、资产负债、合同、关键会计政策。
   - 标注最依赖判断的变量，以及最可能推翻结论的缺失事实。

4. 建立资本回报账本
   - 看期初股东权益、总资本、经营利润、ROE/ROTC、每股账面价值或每股内含价值变化。
   - 检查利润增长是否跟得上资本基数增长。扩大资本后回报率下降，要降低评价。
   - 对多业务公司分段分析，找出创造现金、高回报再投资、吞噬资本和周期拖累的部分。

5. 还原真实盈利
   - 剔除或单独标注一次性资本利得、库存利润、未实现证券损益、权益法滞后、审计时点差异。
   - 检查存货计价、损失准备、费用计提、折旧、税务、或有负债和合同条款。
   - 对保险和银行，重点看承保利润、准备金充足性、平均存款盈利、流动性和受托责任。

6. 做保守价值拆解
   - 普通低估：估算私人所有者价值、正常化盈利、资产价值和可分配现金。
   - 相对低估：只与真正可比对象比较，并考虑整体估值标准下调的风险。
   - Workout：列出预计收款、支付形式、完成日期、失败损失、拖延影响和年化收益。
   - 控股/资产转换：估算快速可实现价值，检查营运资本释放、费用削减、资产出售、税务和治理阻力。
   - 经营型长期持有：估算长期资本回报、可再投资空间、浮存金或存款价值、财务强度和管理层可托付性。

7. 检查价值释放路径
   - 写清楚价值如何被看见或兑现：市场纠偏、时间复利、并购、清算、分拆、回购、资产出售、控制权、经营改善、资本再部署。
   - 区分可等待的催化剂和需要创造的催化剂。创造型路径必须说明持股比例、投票权、盟友、成本和阻力。
   - 若可能等待很久，要求内在价值在等待中继续增长。

8. 评估管理层、董事会和所有者结构
   - 看管理者是否有长期记录、所有者心态、定价能力、成本控制、信息系统和承认错误的能力。
   - 检查董事会是否代表股东，还是代表客户、惯性、费用或规模。
   - 收购或控股时，没有可信管理层要显著降低估值或放弃。

9. 检查财务强度和价格纪律
   - 要求债务期限、利率、流动性、赎回保护、准备金、融资来源和被迫卖出风险说得清。
   - 对保险、银行、制造和零售都问同一件事：新增销量是否以足够价格取得，还是用未来亏损换规模。
   - 行业低迷时，财务强度本身是期权，它让公司能等待好价格并在别人收缩时扩张。

10. 决定仓位、保密和退出
   - 仓位由折价、确定性、下行保护、流动性、资金占用时间、可控程度和替代机会决定。
   - 低风险、高折价、可影响结果的机会可以集中；平庸机会不应靠分散掩饰。
   - 建仓期希望价格沉闷；流动性差和保密可能是优势。
   - 卖出条件：折价收窄、催化剂兑现、风险上升、价值判断被推翻、剩余年化回报不够，或出现更好机会。

## 输出格式

用中文输出，结论先行，写成所有者备忘录：

1. `一句话结论`：买入、持有、等待建仓、卖出、回避或资料不足，以及最关键理由。
2. `机会分类`：普通低估、相对低估、Workout、控股/资产转换、经营型长期持有，或混合。
3. `能力圈与事实边界`：已理解什么，哪些信息不足以判断。
4. `资本回报账本`：经营利润、ROE/ROTC、每股价值、资本基数变化和分业务质量。
5. `真实盈利与会计质量`：需要调整的利润、存货、准备金、税务、未实现损益和合同风险。
6. `估值与安全边际`：保守价值区间、当前价格、折价来源和最脆弱假设。
7. `价值释放路径`：时间、催化剂、控制权、经营改善、资产转换或市场纠偏。
8. `管理层与资本配置`：经营者、董事会、激励、再投资、分红、回购、并购和错误处理。
9. `财务强度与永久损失风险`：债务、流动性、准备金、周期、利率、通胀、监管和失败情景。
10. `机会成本、仓位与退出`：相对替代机会是否值得，适合多大仓位，何时加仓或卖出。
11. `反证清单`：出现哪些事实必须推翻或下调结论。

## 判断准则

- 市场决定什么时候被证明正确，企业分析决定是否正确。
- 便宜必须和防守性相连；只有低价、没有价值保护，不是安全边际。
- 增长不是目标；能在扩大资本基数后仍保持高回报的增长才有价值。
- Workout 的风险是事件失败；普通低估的风险是价值判断错或价值被破坏；控股的风险是买贵、管错或资本被锁死。
- 管理层和董事会不持股、不承认错误、不按真实成本定价时，不要假设他们会像所有者一样行动。
- 等待不是浪费，只要内在价值在等待中增长，且替代机会不更好。
- 高涨市场中找不到足够机会时，不要降低标准；等待、持现金或转向更隔离的事件机会都可以是行动。
- 长期结果必须用事先选定的标尺衡量，但不能期待每年都领先。
- 若资料不足，不要制造巴菲特式确定结论；列出还需要验证的事实。
