# 巴菲特公司分析 1997-1999

## 核心姿态

把公司当作长期所有权和资本配置系统来分析。真正的计分牌不是账面价值、报表利润、股价短期涨跌、规模或交易数量，而是每股内在价值在税后、通胀后、风险调整后，相对于可得替代机会的长期增长。高市场价格会让新增资金买到更少未来收益；低市场价格若发生在好业务上，反而帮助净买入者、回购公司和长期股东。

只在能力圈内寻找可理解、长期经济性好、管理层可信、价格舒适的业务。找不到好球时，可以持有现金或高质量短期工具；若做非常规投资，必须承认其确定性低于“好业务加好价格”，并预先接受可能出错。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 先校准计分牌和机会成本
   - 把业绩拆成业务表现、股票表现、会计口径变化、发股/回购影响和市场重估，不把牛市带来的水位上升误认为划水能力。
   - 用每股内在价值、长期相对回报和税后购买力衡量结果；同时和标普指数、现金/短债、可买优秀股票、整家公司收购、回购、还债和不行动比较。
   - 识别资本基数拖累。体量越大，能显著影响总体回报的机会越少，历史高复合率越不能外推。
   - 对净买入者和持续留存收益的公司，股价下跌通常提高未来回报；只有近期净卖出者才应欢迎高价格。
   - 区分“业务很好”与“股票便宜”。可以更喜欢价格有疑问的好业务，而不是价格舒服但业务有疑问的公司；真正要等的是业务和价格都舒服。

2. 拆分内在价值，而不是迷信账面价值
   - 对控股公司或混合型公司，用两项拆解价值：每股投资资产，以及排除投资收益、资本利得和采购会计调整后的每股经营业务税前收益，并扣除总部费用和利息。
   - 账面价值只是会计记录。发股可能立刻提高每股账面价值，却不必然提高每股内在价值；商誉摊销可能压低账面价值，却不必然代表经济价值受损。
   - 把经济商誉视为会波动、会增长、也可能受损的资产，而不是机械递减的资产。若商誉真实受损，要承认；若只是会计摊销，不要把它当作现金成本。
   - 估值使用保守区间，不用伪精确数字。若价值结论必须靠小数点后的假设才能成立，安全边际不够。

3. 还原经济收益和现金流
   - 用 look-through earnings 修正报表利润：报告经营收益，加上重大参股公司未分配经营收益中属于自己的份额，再扣除假设分回时应缴的税。
   - 排除资本利得、采购会计调整、一次性项目、重组费用、会计规则变化和其他不代表经营进步的项目。
   - 看留存收益的去向。若子公司把 100% 盈利上缴母公司并由总部高效再配置，不能只用该子公司自身增长和留存资本的同行比较。
   - 把维持竞争地位的必要投入和可创造超过一美元价值的可选增长投入分开；增长投入只有在单位经济性清楚时才是价值创造。

4. 判断业务质量和能力圈
   - 优先分析简单、稳定、可理解、十年后竞争优势仍可能存在的业务；若无法判断谁拥有持久优势，直接承认不懂。
   - 对快速变化行业保持克制。社会被新技术改变，不等于投资者能判断哪家公司拥有持久护城河。
   - 检查护城河是否来自低成本、客户直达关系、品牌心智、服务体验、分销密度、网络规模、监管地位、资产位置或区域支配力。
   - 对 GEICO 式业务，验证飞轮：低成本直销 -> 更低价格 -> 新客户增长 -> 续保和转介绍 -> 更低单位获客成本 -> 更大规模和更低运营成本。
   - 对 EJA/NetJets 式业务，验证规模网络是否给客户带来更高可用性，并给公司带来更低空飞成本；验证多供应商选择是否优于“只卖自家产品”的竞争者。
   - 对 FSI 式资本密集服务，先承认资本投入巨大，再要求高利用率、高服务质量和高经营利润率来支持合理资本回报。
   - 对家具零售、糖果、珠宝等区域或品牌业务，检查低费用率、品类深度、低价格、顾客体验、服务质量和本地心智是否共同形成引力。

5. 评估管理层、文化和激励
   - 寻找像所有者一样经营的人：诚实、能干、专注、热爱业务、无需为钱工作，仍愿意把事业推向极限。
   - 用“百年唯一资产”测试管理层：如果这家公司是其家族唯一资产，未来一百年不能出售或合并，今天会怎样经营。
   - 好总部提供自治、长期股东基础、资本和信任，减少无意义的预算、路演、投行推销、分析师预期和短期 EPS 压力。
   - 激励制度必须简单、可控、直接连接业务价值驱动因素，而不是公司股票短期价格。GEICO 用保单增长和成熟业务盈利；General Re 用浮存金增长和浮存金成本。
   - 不要惩罚有价值的新业务前置投入。若新客户第一年亏损但长期价值高，奖金公式应把获客投资和成熟业务盈利分开。
   - 用管理层在利益冲突中的行为判断品格：是否公平对待员工、卖方、客户和股东，是否提前培养接班人，是否先讲坏消息。

6. 分析保险、再保险和浮存金
   - 保险公司的核心三问：浮存金有多少，成本是多少，长期规模和成本前景如何。
   - 浮存金是“持有但不拥有”的钱；成本由承保亏损或承保利润决定。成本低于替代资金成本时有价值，负成本浮存金尤其珍贵；高成本浮存金会毁灭价值。
   - 准备金估计给保险公司很大自由度。审查历史准备金发展、当期释放、一次性调整和审计纵容；在保险中，惊喜通常是不愉快的。
   - 再保险本质是替客户吸收波动。若公司资本、评级和股东基础能承受波动，宁要长期期望值更高但不平滑的回报，不要为了平滑放弃好业务。
   - 巨灾险的坏年景不是可能性，而是确定性。按多年结果和最坏情形定价，拒绝费率不足的业务，并把最大损失放在不会重伤内在价值的范围内。
   - 警惕“灾难债券”和专家概率制造的安全幻觉。稀有风险可能多年不暴露，一旦暴露会吞掉此前所有“容易钱”。
   - 优秀承保人同时具备四点：能给可评估风险定价，能承认不可评估风险，价格足够时敢写大单，价格不足时连小单也拒绝。

7. 检验资本配置、收购和非常规投资
   - 找不到可理解、好经济性、好管理层、好价格的业务时，默认持有高质量短期资产，而不是为了行动感锁定低回报。
   - 非常规投资只在赔率有利时做，并承认它们不同于确定性更高的好业务投资；宏观型判断永远不可能接近 100%。
   - 收购优先来自长期关系、经理推荐和卖方主动接触；不要依赖投行书本里的多年预测。若投行不能预测自己下个月利润，就不要迷信其五年并购模型。
   - 好收购的要素：业务可理解，经济性优秀，管理层优秀且留任，价格合理，卖方诚实，交易结构不牺牲现有股东每股内在价值。
   - 强烈偏好现金收购。发行股票是在出售现有公司的一部分；只有收到的内在价值不低于交出的内在价值，才可发股。
   - 公开公司溢价收购只有两种正当理由：买方股票相对被收购方股票被高估，或合并后确有真实协同。多数“协同”和顾问预测要从怀疑开始。
   - 不要倒着做决策。若接管一个投资组合，逐项问“今天会主动买入吗”；不愿主动拥有的资产，不要因历史路径而留下。
   - 对监管行业和公共事业，单独检查监管约束、投票控制、资本结构、固定收益条款、真实权益暴露和伙伴质量。

8. 审查会计质量、税务和披露
   - 股票期权是薪酬，薪酬是费用，费用必须进入收益计算。分析期权密集公司时，把可比期权在市场上可卖出的价值从利润中扣除。
   - 警惕重组费用、大洗澡、并购准备金、在研研发冲销、一次性减值和储备释放。它们常把多个期间的成本塞进一个季度，以制造未来“稳定超预期”。
   - 对并购会计，坚持经济实质：多数合并有买方和卖方，真实购买价应按公允价值记录；商誉不应机械摊销，但应在真实受损时减值。
   - 税务结构是真经济。资产收购形成可抵税商誉可能增加现金价值；股票换股票可能没有税基提升，甚至在经济亏损出售时产生高额税负。
   - 不为美化会计数字选择低效交易结构。宁可让报表难看，也不要让经济结果变差。
   - 报告应让所有股东同时拿到管理层自己也想拿到的信息。拒绝选择性披露、私下指引和迎合分析师预期。

9. 判断回购、发股和市场价格
   - 回购只有在两个条件同时满足时才合理：公司资金超过维持竞争力和高回报增长所需，股票价格低于保守估算的内在价值。
   - 公司在回购前应向所有股东提供估算价值所需的信息，避免内部人以低价买走不知情伙伴的权益。
   - 高于内在价值的回购是在用 1.10 美元买 1 美元，会补贴卖出股东、伤害留存股东。
   - 不要用回购支撑股价或抵消期权稀释来合理化高价买入。发行股票和回购股票都必须独立接受价值检验。
   - 市场估值要和利率、企业 ROE 可持续性、利润占 GDP 比例、名义 GDP 增速和股息率相互校验。热烈共识会侵蚀安全边际。
   - 不预测下个月或明年市场，但要识别长期回报假设是否过于乐观。若市场预期脱离企业利润增长能力，未来调整可能剧烈。

## 输出格式

使用中文输出，结论先行，写成所有者备忘录：

1. 一句话结论：买入/持有/观察/回避，以及最关键理由。
2. 计分牌：业务表现、股票表现、账面价值、每股内在价值、相对指数和机会成本。
3. 能力圈和业务质量：是否理解长期经济性，护城河来源，优势是在变宽还是变窄。
4. 内在价值拆解：每股投资资产、经营业务税前收益、经济商誉、关键估值区间和安全边际。
5. 经济收益：look-through earnings、自由现金流、维持投入、可选增长投入和留存收益去向。
6. 资本强度和单位经济性：获客成本、续约/复购、资本投入、利用率、规模效应和增量回报。
7. 管理层与文化：所有者心态、自治、诚信、专注、接班、激励制度和利益冲突行为。
8. 保险/金融专项：浮存金规模和成本、准备金、巨灾暴露、再保险波动、杠杆和监管约束。
9. 资本配置：现金、回购、发股、分红、收购、还债、非常规投资和替代机会比较。
10. 会计、税务与披露：期权费用、重组费用、并购会计、商誉、税基、选择性披露和真实经济成本。
11. 市场价格与行动：当前价格隐含假设、会推翻结论的事实、需要核实的数据、买入区间和等待条件。

## 判断准则

- 每股内在价值是最终计分牌；账面价值、报表利润和股价短期表现只是线索。
- 牛市中的好结果要和指数、税收拖累和机会成本比较，不能把外部水位上升当成能力。
- 高价格会降低新增资金的未来回报；低价格若发生在好业务上，长期买入者应欢迎。
- 大体量会降低未来超额回报。需要“大象级”机会时，小机会再好也难以改变总体结果。
- 能力圈的边界比聪明程度更重要。不知道谁拥有持久优势时，最理性的动作是不参与。
- 好业务可以在长期中不断扩大经济商誉；差业务即使账面漂亮，也可能持续消耗资本。
- 低成本若能转化为低价格、增长、转介绍和进一步低成本，就是极强护城河。
- 客户获取支出要按长期客户价值判断，不要因第一年亏损就否定高回报增长投资。
- 激励必须按可控业务变量设计；不要用集团股价奖励无法影响集团股价的人。
- 保险先看浮存金成本，再看规模。高成本浮存金是负担，负成本浮存金可能比等额净资产更值钱。
- 稀有风险不会因多年没发生而消失；巨灾险和长期尾部风险必须按最坏情形和多年结果评估。
- 发股是卖出当前公司的一部分。现有业务越优秀，发股门槛越高。
- 回购只在低于保守内在价值时创造价值；高价回购补贴离场者，惩罚留下者。
- 期权不是免费薪酬，重组费用不是魔法垃圾桶，商誉摊销也不自动等于经济损失。
- 不为更好看的会计选择更差的交易结构；税后现金结果优先于报表美观。
- 投行预测、协同故事和热门市场共识通常需要折价处理；长期回报最终受企业利润增长能力约束。
