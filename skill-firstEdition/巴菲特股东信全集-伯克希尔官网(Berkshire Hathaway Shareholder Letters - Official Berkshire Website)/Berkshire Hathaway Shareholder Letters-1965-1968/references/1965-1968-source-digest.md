# 1965-1968年信件来源摘要

本参考文件来自用户提供的1965、1966、1967、1968年中文 PDF 文本。只在需要追溯方法论出处或解释框架来源时读取。

## 1965

- 把投资分为 `Workout`、`普通股-私人所有者价值`、`控制权投资`、`普通股-相对低估`。
- Berkshire Hathaway 从普通股投资转为控制权投资后，巴菲特不再把市场报价涨跌当作收益或损失，而是按实际拥有的生意看待。
- 保守估值依据包括资产、盈利能力、行业境况、竞争地位。
- 组合可以高度集中：若预期回报巨大且价值剧烈改变概率很小，可把净资产很大比例投向单一证券。
- 反对为形式安全而过度分散；持有过多股票会导致不了解每个标的。

## 1966

- 收购 Hochschild, Kohn 时强调：买整个生意与买股票原则相同，仍要做定量与定性评估；没有优秀管理层，即使更便宜也未必买。
- 明确拒绝市场预测：买卖股票时考虑公司会怎样，不考虑市场会怎样。
- 市场决定何时被证明正确，企业分析决定是否正确。
- 不因市场下跌预测而卖出低估证券，也不因市场上涨预测而买入已合理反映价值的证券。
- 控制权投资收益来自经营利润、买入被低估的受控公司股票、受控公司持有证券的增值，但账面收益可能不能完整反映经济收益。
- 对普通股投资持续比较新旧想法；新想法不优于旧想法就维持原有投资。
- 接受短期不良表现以换取长期良好表现，但不接受永久性本金损失。

## 1967

- 承认市场环境变化、资金规模扩大、竞争加剧和个人动机变化会降低未来回报。
- 估值同时包含定性与定量：极端定性会忽略价格，极端定量会忽略企业；实际必须两者兼顾。
- 巴菲特自认出身于定量学派，但最满意的大投资常来自定性洞察；定性洞察稀少且不可量化。
- 统计意义上的明显便宜货越来越少，不应为了追赶市场潮流而做自己不理解的方法。
- 坚守能力圈：不投资关键因素无法理解的技术型生意或流行投机方式。
- 诚实调低目标：从长期超越道指10个百分点，降为更现实的长期目标，并允许合伙人退出。

## 1968

- 上半年和全年业绩极好，但强调集中持仓会带来不稳定，不应因短期结果过度兴奋。
- 对准备永久持有的控股公司，不能靠二级市场买卖差价赚钱，而要靠企业本身提供满意长期回报。
- 提醒市场泡沫和财报扭曲会让公司获得表面利益，但短期和长期价值都可能存疑。
- 对 Berkshire 的估值示例说明：市场价可高可低，但控股公司的内在评估取决于生意，而非报价。
- 1968年收益再次主要由少数点子贡献，进一步说明机会稀缺和集中投资的现实。
