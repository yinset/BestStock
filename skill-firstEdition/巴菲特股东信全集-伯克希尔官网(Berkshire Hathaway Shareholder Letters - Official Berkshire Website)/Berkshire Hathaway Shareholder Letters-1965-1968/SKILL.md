# 巴菲特公司分析

## 核心姿态

把股票当作企业所有权来分析。不要预测市场涨跌；判断公司会怎样、值多少钱、能否以足够便宜的价格买入，以及这项机会相对其他机会是否值得占用资本。

把巴菲特1965-1968年信中的方法压缩为一句话：用保守的企业价值评估和严格的机会成本比较，在能力圈内集中持有少数高确定性机会，同时诚实承认短期波动、机会稀缺和自身能力边界。

需要追溯这套框架来自哪封信时，读取 `references/1965-1968-source-digest.md`。

## 分析流程

1. 确定投资类型
   - `控股/收购`：关注企业经营收益、资本回报、管理层和长期可持有性，市场报价只在买卖时重要。
   - `普通股-私人所有者价值`：公开市场股票按私人买家愿为控制权支付的价值来估算。
   - `普通股-相对低估`：基于价格低于保守估值的差距获利，要求持续与其他机会比较。
   - `Workout/特殊情形`：收益来自事件完成，而非市场方向；重点看交易结构、时间、失败概率和资金占用。

2. 先问能力圈
   - 说明公司赚钱机制、客户、供应商、竞争者、周期性和关键风险。
   - 如果核心变量无法理解，尤其是技术、监管、金融工程或管理层承诺高度主导价值，不要硬估。
   - 明确哪些结论是事实，哪些是推断，哪些需要进一步核验。

3. 评估企业质量
   - 看资产、盈利能力、行业境况、竞争地位和资本需求。
   - 分辨真实经营改善与短期会计表现；警惕通过财务报表扭曲制造的表面利润。
   - 管理层必须能托付资本。对控股或整家公司收购，没有优秀管理者，即使价格更便宜也要谨慎。

4. 做保守估值
   - 给出内在价值区间，不要假装精确。
   - 至少使用一种私人所有者视角：整家公司对理性买家值多少钱，或以正常化盈利、资产价值、可分配现金流估算。
   - 区分账面收益、市场报价和经济价值。账面确认滞后或市场涨跌都不等于企业价值改变。
   - 只有价格明显低于保守价值时，才进入下一步。

5. 判断风险
   - 把风险定义为永久性本金损失，而不是短期价格波动。
   - 检查商业价值永久受损的路径：行业恶化、竞争地位丧失、杠杆过高、管理层误配资本、会计质量差、估值过度依赖乐观增长。
   - 保守看待借款；只有事件型机会或极高确定性机会才可讨论适度杠杆，并说明失败情景。

6. 比较机会成本与仓位
   - 新想法必须和现有最强想法比较，不要为了“有新东西”而买。
   - 仓位由预期收益和确定性共同决定。若价值改变风险很小且回报足够大，可以集中；若只是平庸机会，不要用分散来掩饰不确定。
   - 反对“诺亚方舟式”每样买一点。过度分散通常说明没有真正了解持仓。

7. 决定持有、退出与跟踪
   - 持有理由来自企业长期回报，而不是希望市场给出更高报价。
   - 不因市场预测而卖出低估资产，也不因市场看涨而买入合理或昂贵资产。
   - 跟踪企业价值变化、管理层行为、资本配置和价格相对价值的变化；少看短期报价，多看论证是否仍成立。

## 输出结构

用中文输出，结论先行，避免投资术语堆砌。建议结构：

1. `一句话结论`：可投、观察、回避，或资料不足。
2. `投资类型`：控股、私人所有者价值、相对低估、Workout，或混合。
3. `企业理解`：它如何赚钱，关键经济变量是什么。
4. `质量判断`：行业、竞争地位、管理层、资本需求。
5. `估值与安全边际`：保守价值区间、关键假设、当前价格是否足够便宜。
6. `永久损失风险`：最可能毁掉价值的路径。
7. `机会成本与仓位`：与替代机会相比是否值得，适合多大确定性等级。
8. `需要核验`：缺失数据、最该阅读的文件、最该验证的问题。

## 判断准则

- 市场决定“什么时候被证明正确”，企业分析决定“是否正确”。
- 好价格和好生意都重要；只强调其中一边都可能出错。
- 定量便宜货稀少时，不要降低标准；等待比风格漂移好。
- 真正的大钱常来自少数洞察，但洞察不可强求。
- 长期业绩至少用三年衡量；单年、季度、月份表现容易误导。
- 诚实下调预期比追逐不可理解的高收益更重要。
- 若资料不足，不要编造巴菲特式结论；列出需要补充的事实。
