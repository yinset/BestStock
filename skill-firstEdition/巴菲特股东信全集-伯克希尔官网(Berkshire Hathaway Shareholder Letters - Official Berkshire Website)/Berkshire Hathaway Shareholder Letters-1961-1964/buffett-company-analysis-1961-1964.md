# 巴菲特合伙人时代投资分析方法论

来源：1961–1964年巴菲特致合伙人信件，提炼自真实案例（Dempster Mill、Texas National Petroleum等）。

---

## 核心世界观（先建立视角，再动手分析）

**业绩基准永远是道琼斯指数，而非绝对收益。**
- 熊市跌得比大盘少 = 成功
- 牛市跟不上大盘 = 正常
- 绝不预测市场走势，只判断个股价值

**三年是最短的评估周期。** 一年的结果没有意义，尤其对于控股类投资。

**安全边际（Margin of Safety）是一切的前提。** 宁可错过机会，也不在没有足够安全边际的情况下买入。

---

## 三种投资类型及分析框架

### 类型一：GENERALS（普通低估股）

**定义：** 市场价格远低于内在价值的证券，无法左右公司决策。

**分析步骤：**

1. **估算清算价值（最保守底线）**
   ```
   清算价值 = （现金 + 应收账款 + 存货）- 全部负债
   ```
   若市价 < 清算价值的 70%，进入深度研究。

2. **估算账面净资产（Book Value）**
   ```
   每股净资产 = 总资产 - 总负债 / 总股本
   ```
   Dempster案例：每股净资产$72，市价$18，折价75%。

3. **评估盈利能力**
   - 当前利润率是否合理？还是被管理不善压制了？
   - 若是管理问题而非行业问题，则存在修复空间（巨大的安全边际）

4. **判断价值实现路径**
   - 路径A：市场自然认可（被动等待）
   - 路径B：持续买入直至控股（主动推动）
   - 若两条路都走不通，则不买。

5. **仓位原则**
   - 重仓5-6只：每只占总资产5%-10%
   - 轻仓10-15只：每只占更小比例
   - 绝不过度集中，也绝不过度分散

**风险提示：** 牛市中这类股票表现最好，熊市中跌幅也可能最大。

---

### 类型二：WORKOUTS（套利/事件驱动）

**定义：** 收益取决于公司具体事件（并购、清算、重组、分拆），而非市场供求。

**分析步骤：**

1. **确认触发事件已公告**
   - 不介入未经公告的谣言（TNP案例：1962年4月正式公告才买入）
   - 公告后买入，而非消息前埋伏

2. **建立收益测算模型**
   ```
   年化收益率 = （预计获得金额 - 当前买入价）/ 买入价 / 预计持有月数 × 12
   ```
   TNP债券案例：持有不足5个月，年化收益约20%

3. **评估事件失败概率**
   - 管理层是否支持？（管理层主导的交易失败概率极低）
   - 监管障碍是什么？（IRS裁决、反垄断审查）
   - 最坏情况下损失多少？

4. **跟踪时间线**
   - 定期与公司沟通，记录每次对话的预期时间节点
   - 时间拖延 ≠ 交易失败，需区分"延期"与"风险上升"

5. **杠杆使用规则**
   - 可以对WORKOUTS使用借贷，上限：不超过净资产25%
   - 理由：确定性高，持有期短

**特点：** 与大盘相关性极低。熊市中是组合的"压舱石"。

---

### 类型三：CONTROLS（控制性投资）

**定义：** 获得目标公司控制权或重大影响力，主动改善经营。

**分析步骤：**

1. **买入前提：先作为GENERALS买入**
   - 初始买入必须满足GENERALS的低估标准
   - 长期持续买入，逐步提升持股比例

2. **判断介入时机**
   - 买入后6-12个月，若管理层无法自我改善，则需换人
   - Dempster：上任新总裁失败后，6个月内引入Harry Bottle

3. **价值改善四板斧**
   ```
   ① 降低运营成本（Cost Reduction）
   ② 削减管理费用（SG&A Reduction）
   ③ 优化资本配置（Capital Reallocation）→ 将滞销存货变现为证券
   ④ 改善存货周转（Inventory Turnover）
   ```

4. **估值方式（非上市公司）**
   ```
   公允价值 = 证券类资产（按市值）+ 经营资产（保守估算）
   ```
   Dempster最终估算：证券部分$35/股 + 制造部分$16/股 = $51/股，最终以$80/股卖出。

5. **退出策略**
   - 整体出售给战略买家
   - 或改善后重新上市
   - 持有期通常3-5年，不以短期市价衡量成败

**特点：** 买入资金越大，竞争者越少（大公司关注者少）。与大盘完全无关。

## 公司分析核查清单

### 财务健康度（必看）
- [ ] 市价 / 清算价值 的比率（越低越好，<0.7为理想）
- [ ] 市价 / 每股净资产 的比率
- [ ] 流动比率（流动资产/流动负债）
- [ ] 存货周转率（是否有滞销问题）
- [ ] 利润率趋势（是结构性问题还是管理问题？）

### 管理层质量（针对CONTROLS）
- [ ] 现有管理层是否有能力/意愿改善现状？
- [ ] 是否需要引入外部管理者？
- [ ] 资本配置历史：钱花在哪里了？

### 行业判断
- [ ] 行业困境 vs. 公司个体问题（能否区分？）
- [ ] 行业是否有定价权？
- [ ] 是否面临技术替代风险？

### 安全边际评估
- [ ] 即便最坏情况（清算），是否仍能保本？
- [ ] 投资论点的核心假设是什么？假设失败的后果？
- [ ] 如果持有3年价值仍未被认可，接下来怎么办？

## 业绩评估框架

**年度评估标准（道琼斯为基准）：**

| 市场环境 | 期望表现 | 说明 |
|---------|---------|------|
| 道琼斯下跌35-40% | 只下跌15-20% | 核心优势所在 |
| 道琼斯持平 | 盈利约10% | WORKOUTS贡献 |
| 道琼斯上涨20%+ | 努力跟上大盘 | 最难的情况 |

**长期目标：** 年均复合增长率超过道琼斯指数约10个百分点。

**复利威力提醒（决策时的心理锚点）：**
- 15%年化 × 10年 = 本金×4倍
- 15%年化 × 20年 = 本金×16倍
- 10%与15%之间的差距，30年后是4倍的财富差距

## 常见认知误区（避坑清单）

❌ **误区1：** 买蓝筹股就是保守投资
→ 不考虑市盈率和分红的蓝筹股充满风险

❌ **误区2：** 债券/国债是保守投资
→ 长期持有可能导致购买力实质下降

❌ **误区3：** 短期跑赢大盘代表方法正确
→ 至少3年，最好经历完整市场周期才能评判

❌ **误区4：** 资金规模增大会提升所有类型投资的收益
→ GENERALS和WORKOUTS受规模负面影响；只有CONTROLS受益于规模增大

❌ **误区5：** 市场价格波动代表真实价值变化
→ 控股公司后，市价不再重要，只有资产内在价值才重要

## 快速判断模板

**面对一只股票，按此顺序思考：**

```
第一步：这是哪类机会？
  → 有公告事件？→ WORKOUTS框架
  → 价格极度低估？→ GENERALS框架（可能演变为CONTROLS）
  → 已有控股机会？→ CONTROLS框架

第二步：安全边际够吗？
  → 清算价值 > 市价？ → 有底线保护
  → 最坏情况损失可接受？ → 可以买入

第三步：价值实现路径是什么？
  → 有明确触发器（事件/管理改善/市场认可）？
  → 时间预期合理（3年内）？

第四步：仓位是否合适？
  → 高确定性 → 可以重仓（5-10%）
  → 中等确定性 → 轻仓（1-3%）
  → 无法回答第二三步 → 不买
```
