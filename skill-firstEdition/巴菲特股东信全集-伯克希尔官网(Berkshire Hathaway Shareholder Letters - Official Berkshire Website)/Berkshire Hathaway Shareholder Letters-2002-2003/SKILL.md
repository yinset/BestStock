# 巴菲特公司分析 2002-2003

## 核心姿态

把公司当作长期所有权、资本配置和风险承诺系统来分析。真正的计分牌是每股内在价值相对于低成本指数和其他机会的长期增长；账面价值、报表利润、实现资本利得和年度股价只是线索。公司应被看成一部正在展开的电影，而不是某一时点的照片。

在行动前先问四件事：这门生意的长期经济性是否可理解，经理是否能干且诚实，价格是否有安全边际，风险是否会在压力环境中相关爆发。找不到好机会时，持有现金和短期国债是合格动作；为了多一点收益而降低信用标准、延长期限、增加杠杆或买入不懂的资产，是资本配置错误。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 校准计分牌
   - 先估每股内在价值，再看账面价值是否只是保守代理。不要把账面价值增长、会计利润或市场涨跌直接等同于价值增长。
   - 与低成本指数基金和可替代机会比较。若长期不能跑赢股东自己可以买到的指数，公司管理层没有创造增量价值。
   - 分清单年表现和长期能力。下跌市场中的相对优势、牛市中的落后、一次性利好或利空，都不能单独决定公司质量。
   - 警惕增长率展示。起点过低、终点过旺、选择性时间区间会制造漂亮复合率；要求同时给出多个起点和正常化终点。
   - 承认规模拖累。资本越大，能影响整体结果的机会越少；过去高复合率不能外推。

2. 还原经济收益
   - 把经营收益、资本利得、汇兑损益、债券交易收益、采购会计调整、商誉摊销或减值、一次性费用和正常周期波动分开。
   - 反向审查 pro forma 和 adjusted earnings。若管理层只要求你忘掉坏项目，也要问有没有同样剔除好运气。
   - 对保险公司要正常化巨灾年份。没有巨灾的承保利润不代表常态；有巨灾也不是可以永远剔除的异常。
   - 对利率、债券、汇率或金融产品带来的短期收益，判断它是否可重复，是否来自可持续能力，是否会在一两年内消失。
   - 折旧、维护资本开支、安全投入、训练投入和服务质量支出都是真实经济成本。不要用 EBITDA 掩盖资本消耗。
   - 实现资本利得对分析意义有限。出售时点不应服务于报表利润，而应服务于价格和机会成本。

3. 判断业务质量和能力圈
   - 优先选择可理解、长期经济性稳定、现金流可保守估计的业务。无法评估数量、时间和确定性时，标记为能力圈外。
   - 寻找持久优势：低成本、品牌心智、分销密度、区域领导、客户信任、服务质量、监管结构、规模效率或特殊资产。
   - 对薄利行业，看规模、执行和成本控制是否足以产生合理资本回报；销售额巨大但税前利润率极薄，不能自动视为好生意。
   - 对融资驱动业务，拆开产品价值和信贷质量。若销量依赖把坏贷款转给天真的资金提供者，增长本身就是风险。
   - 对资本密集服务业务，检查资产利用率、维护投入、折旧、库存跌价、客户节省和服务差异化是否能形成长期利润。
   - 对收购来的业务，同时看有形净资产回报和包含商誉后的账面回报。高商誉会降低真实投入资本回报。

4. 评估收购
   - 只在三项同时成立时买整家公司：长期经济性好，经理优秀且诚实，价格理性。买入后默认长期持有，不依赖退出策略。
   - 交易结构要保护老股东。发行股票等于出售现有业务的一部分；现金和确定性报价常比复杂金融工程更诚实。
   - 卖方质量是尽调线索。可信卖方、直率经理、清楚账目和长期声誉可降低摩擦；拍卖式包装和最高价冲动要提高警惕。
   - 从错误中学习。一次糟糕的行业投资或债务投资，应转化为对商业模式、融资链条和管理层行为的识别能力。
   - 对本地服务或经销网络，保留地方品牌和经理自治；不要用总部想象替代一线关系和本地知识。
   - 对周期性资产，不要用高峰利润出价，也不要因低谷利润否定好业务；看正常化利润和重整后经济性。

5. 分析保险、再保险和浮存金
   - 保险公司三问：浮存金有多少，成本是多少，数量和成本的长期前景如何。
   - 浮存金是持有但不拥有的钱。若长期成本低于替代资金成本，它有价值；若成本高于市场资金成本，它是负担。
   - 低成本浮存金不是自动产生的，必须来自承保纪律、保守准备金和避免风险聚合。
   - 承保纪律包括：只写能力圈内风险，只写计入远端情景后仍有正期望的风险，限制单一事件和相关事件累计暴露，拒绝道德风险。
   - 准备金是保险分析核心。低估准备金会虚增利润、误导奖金、提前纳税，并让真实成本多年后集中爆发。
   - 长尾保险利润容易被管理层“想要”的数字支配。审查历史准备金补提、释放、精算假设、审计意见和管理层话术。
   - 再保险只买最强对手方的承诺。便宜再保险若无法收回，就是昂贵灾难；对方财务实力比费率更关键。
   - 对巨灾和异常风险，用最大损失、现值暴露、相关性、对手方链条和公司生存能力测试，而不是看历史平静期。

6. 审查衍生品和复杂金融风险
   - 把长期、复杂、难退出的衍生品视为潜在资本占用和流动性风险，而不是只看当期利润。
   - 区分有市场价格的 mark-to-market 与模型估值。多变量、长期限、缺少真实市场的合同，容易从模型估值滑向幻想估值。
   - 检查交易员、CEO和奖金制度是否受益于提前确认利润。若激励先兑现、现金多年后才验证，风险很大。
   - 压力测试降级触发的抵押品要求。信用评级下降会让衍生品同时索取现金，放大本来无关的经营困难。
   - 追踪链式风险。看似分散的应收对手方，可能在同一外部冲击下同时相关违约。
   - 阅读披露后如果仍无法理解风险，不要用“披露很多”代替“风险清楚”。复杂性本身就是拒绝理由。
   - 只在风险可衡量、流动性高、信用风险极低且报酬足够时使用金融工具。公司的堡垒式财务强度优先于额外收益。

7. 分析资本配置和融资
   - 资本配置顺序随价格变化：股票显著便宜时买股票，债券便宜时买债券，符合标准的整家公司随时可以买。
   - 资本闲置是痛苦但可接受的状态；愚蠢行动更痛苦。默认仓位可以是短期国债和回购协议。
   - 不为多一点收益降低信用标准、延长久期或承担小概率大损失。小风险若没有充分补偿，也不值得承担。
   - 困境债和垃圾债要逐只做价格价值计算。标的通常债务重、行业回报低、管理层质量参差，必须预期会有个别大损失。
   - 宏观判断要谦逊。只有当公司已有巨大单一货币或利率暴露，且对冲价格合理时，才把宏观风险作为部分抵消工具。
   - 子公司融资坚持“各桶自立”。贷款业务应按真实资金成本经营，不能依赖富有母公司的无成本补贴。
   - 债务只有在资产现金流稳定、期限匹配、无追索或风险边界清楚时才合理；稳定受监管公用事业和优质应收账款可例外。

8. 评估管理层、董事会和文化
   - 寻找能干、诚实、热爱业务、像所有者一样经营的人。总部的价值在于配置资本、选择经理和维护文化，而不是干预一线。
   - 管理层应把股东当合伙人，不是营销对象。报告要给出如果角色互换时你也想知道的信息。
   - 真正独立的董事需要三项：业务判断力、股东导向、对公司有真实兴趣。形式独立不等于敢挑战强势CEO。
   - 董事和管理层最好用真金白银持有大量股票，而不是靠期权、限制股或董事费获得无下行收益。
   - 董事会的两项硬任务是选择或更换CEO，以及阻止能干但贪婪的经理过度拿走股东财富。
   - 薪酬委员会要能代表所有者谈判。若顾问、HR和董事都不真正替股东心疼钱，CEO薪酬会失控。
   - 文化检验看危机和错误处理。好文化具体承认错误、快速纠正、保护声誉；坏文化用口号、形式改革和公关广告替代受托责任。

9. 审计委员会和会计质量检查
   - 审计委员会本身不能审计，关键是迫使外部审计师把知道或怀疑的问题说出来。
   - 在财报发布前至少问审计师四个问题：
     1. 如果审计师独自负责报表，会不会用不同会计处理。
     2. 如果审计师是投资者，是否已用清楚语言得到理解业绩所需的信息。
     3. 内部审计程序是否等同于审计师自己当CEO时会采用的程序。
     4. 审计师是否知道任何把收入或费用在期间之间搬移的会计或经营动作。
   -  visible 的弱会计是后台问题的信号。股票期权不费用化、养老金假设幻想、脚注难懂、选择性披露，都要扣分。
   - 对 EBITDA 保持怀疑。折旧代表先付现金后的经济消耗，不是无关紧要的非现金项目。
   - 对持续宣称可平滑增长、总能达成指引的管理层提高警惕。总说能“完成数字”的人，最后可能会“制造数字”。
   - 脚注和解释若让人看不懂，通常不是你不够聪明，而是管理层不想让你看懂。

## 输出格式

使用中文输出，写成所有者备忘录，结论先行：

1. 一句话结论：买入、持有、观察或回避，以及最关键理由。
2. 计分牌：每股内在价值、账面价值的适用性、长期相对指数、资本规模拖累和机会成本。
3. 正常化收益：经营收益、资本利得、一次性项目、好运气、坏运气、会计调整和真实资本开支。
4. 业务质量：能力圈、长期经济性、护城河来源、周期性、资本强度、客户价值和增量回报。
5. 管理层与治理：经理能力、诚实、所有者心态、董事会独立性、薪酬、继任、错误复盘和文化。
6. 收购与资本配置：现金、股票、回购、分红、债务、收购、困境债、现金等待和行动门槛。
7. 保险与金融专项：浮存金成本、准备金、承保纪律、再保险对手方、巨灾聚合、衍生品和流动性风险。
8. 会计与披露：pro forma、EBITDA、脚注、养老金、期权、审计委员会问题、指引和管理层话术。
9. 估值与行动条件：当前价格隐含假设、保守价值区间、安全边际、反证清单、必须核实的数据和等待条件。

## 判断准则

- 每股内在价值是最终计分牌；账面价值只在能保守近似内在价值时有用。
- 报表利润必须被正常化。好运气和坏运气都要承认，不能只剔除让利润难看的项目。
- 优秀业务也可能有薄利、周期或短期亏损；核心是长期资本回报和竞争位置是否改善。
- 不能理解长期现金流时，最诚实的结论是等待或回避。
- 浮存金先看成本，再看规模。高成本浮存金不是资产，是杠杆化负担。
- 准备金、衍生品和复杂融资的危险在于多年后才验证；当前利润越漂亮，越要问现金何时验证。
- 信用标准不可为收益率让步。资本保全和流动性选择权本身有巨大价值。
- 形式独立不等于真实独立。董事必须懂业务、站在股东一边，并有足够所有权让自己疼。
- 审计师若没有被审计委员会逼到必须表态，审计质量常会让位于管理层关系。
- 能长期等待，是资本配置能力的一部分。
