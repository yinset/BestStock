# 公司分析方法论：巴菲特范式

> 来源：伯克希尔·哈撒韦1986、1987、1988年度股东信（沃伦·巴菲特著）

---

## 一、核心认知：账面价值 ≠ 内在价值

**最高原则**：真正重要的是**内在商业价值**（Intrinsic Business Value），而非GAAP账面价值。

- 账面价值是历史成本的累积，内在价值是所有未来现金流的折现
- 两者可以严重背离（LTV账面价值6.52亿美元却破产；Belridge Oil账面价值1.77亿却被以36亿美元出售）
- 在伯克希尔，内在商业价值**稳定高于**账面价值，且差距持续扩大——这是优秀企业的标志

**实操原则**：  
分析任何公司时，先问：*账面价值与内在价值的差距有多大？差距是在扩大还是缩小？*

## 二、所有者收益公式（Owner Earnings）

这是巴菲特最重要的估值工具，替代GAAP净利润：

```
所有者收益 = (a) 报告净利润
           + (b) 折旧、摊销及其他非现金费用
           - (c) 维持竞争地位和产量所需的年均资本支出
```

**关键说明**：
- GAAP"现金流"= (a)+(b)，**不扣除(c)**，是误导性指标
- 投行和销售材料常用(a)+(b)来粉饰债务偿还能力，要高度警惕
- (c)必须估算，是软数字，但"宁可模糊地正确，也不要精确地错误"（凯恩斯语）
- 当(c) ≈ (b)时，GAAP净利润≈所有者收益；当(c) >> (b)时，GAAP严重高估真实盈利

**购价调整对GAAP的扭曲**：  
收购溢价会被分配到被收购公司的资产上，产生额外折旧和摊销，**降低**GAAP利润但不影响真实经济价值。分析被收购公司时，应还原为"如未被收购"的盈利数字来评估管理层绩效。

## 三、经济护城河识别框架

### 3.1 商品型业务 vs 特许经营型业务

| 维度 | 商品型（Commodity） | 特许经营型（Franchise） |
|------|-------------------|----------------------|
| 产品差异化 | 几乎没有 | 显著 |
| 定价权 | 无，随市场波动 | 强，可自主提价 |
| 超额利润持续性 | 仅在短缺期 | 长期持续 |
| 税收优惠归属 | 传导给消费者 | 留存给股东 |
| 典型行业 | 保险（大部分）、铝、汽车 | See's糖果、世界图书、水牛城新闻 |

**护城河的税收测试**（独特方法）：  
当企业税率降低时，若减税收益**流向消费者**（价格下降）→ 商品型；若减税收益**留给股东**→ 特许经营型。监管型公用事业是例外（监管迫使传导）。

### 3.2 低成本护城河

GEICO案例：费用率（承保费用+损失调整费用/保费）仅23.5%，比主要竞争对手低15个百分点。

> "GEICO成本与竞争对手的差距，就是保护这座商业城堡的护城河。"

**低成本护城河评估要点**：
- 成本优势是结构性的还是偶发性的？
- 管理层是否在持续加深护城河（GEICO每年进一步压低费用率）？
- 低成本能否转化为定价优势而非仅仅更高利润率？

### 3.3 品牌/习惯护城河

See's糖果案例：
- 产品独特的"个性"（口味+适中价格+完全掌控配送+优质服务）
- 消费者愿意为情感价值额外支付
- 极度季节性（85%利润在12月）但长期稳定

## 四、管理层评估：三维标准

### 4.1 能力维度

**核心指标**：在**较少资本**投入下实现**较大收益**增长。

- 伯克希尔七大业务（水牛城新闻、Fechheimer等）：1.75亿权益资本，税前收益1.78亿 → **ROE约57%**
- 对比基准：《财富》1000强中，10年平均ROE超过30%的仅6家
- 评估时，用历史成本资产基础评判管理层，而非收购溢价后的账面价值（收购价格影响买方回报，不影响管理层真实绩效）

**能力的最高证明**：在业务规模扩大、竞争加剧的情况下，仍能维持高ROE。

### 4.2 资本配置能力（最被低估的管理层技能）

- CEO晋升路径通常经由营销、生产、工程，**极少经历系统性资本配置训练**
- 10年内，一个每年保留10%净资产利润的CEO，将主导超过60%的在用资本配置
- 资本配置差的CEO特征：依赖咨询公司和投行建议；频繁"重组"；收购成瘾

**评估资本配置能力的问题**：
1. 历年保留收益产生了多少增量市值？
2. 股票回购是在合理价格还是高价进行？
3. 分红政策是否反映了对资本再投资机会的真实判断？

### 4.3 品格维度

**"像股东一样思考"是最高赞美**。识别标志：
- 有大量个人财富但仍保持激情（不为金钱工作，为热爱工作）
- 诚实披露坏消息，不美化业绩
- 坚守原则，在竞争压力下不降低标准（水牛城新闻50%新闻版面承诺）
- 不因短期利润丰厚就增加无用人员；不因利润下滑就削减核心投入

**警惕信号**：
- 储备金长期低估（保险公司常见）
- 通过会计操纵平滑收益
- 业绩标准不存在或随时被豁免
- 董事会与CEO关系"太过融洽"

## 五、行业分析：以保险业为模型

保险业是理解大多数行业周期的最佳模型：

### 5.1 承保周期机制
```
保费增速 < 10%（均衡点）→ 承保损失累积
→ 亏损显现 → 资本不足 → 竞争者退出
→ 价格飙升 → 利润暴增 → 新资本涌入 → 产能过剩
→ 价格崩溃 → 循环往复
```

**数据规律**：综合赔付率（总保险成本/保费收入）107-111范围内，考虑浮存金投资收益后约为盈亏平衡。

### 5.2 浮存金（Float）：保险业的独特价值

- 浮存金 = 保单持有人资金（先收保费，后付赔款）
- 如果承保做到收支平衡甚至微利，浮存金相当于**零成本或负成本**的融资
- 评估保险公司：**浮存金/保费比率**，比率越高越有价值

### 5.3 商品型行业的生存策略

两种差异化路径（保险，可推广至其他商品型行业）：
1. **绝对低成本**（GEICO模式）：结构性成本优势，任何周期都能盈利
2. **极度自律**（伯克希尔模式）：完全按风险定价，不追逐市场份额，在别人恐慌时进场

## 六、投资哲学：Mr. Market框架

### 6.1 Mr. Market隐喻

把市场报价想象为一个情绪失常的生意伙伴——每天给出买卖报价，但其报价由情绪驱动而非理性。

**运用原则**：
- 利用他，不要被他引导
- 市场短期是投票机，长期是称重机
- 在别人贪婪时恐惧，在别人恐惧时贪婪
- 若不能比Mr. Market更好地评估企业价值，就不该参与这个游戏

### 6.2 永久持有标准

满足以下条件的投资，目标持有期为"永远"：
- 企业经济前景持续良好
- 管理层有能力且诚实
- 市场未对企业严重高估

**不卖出的条件**：持股增值、长期持有——这些不是卖出理由。唯有基本面恶化或出现显著更佳机会，才考虑调整。

### 6.3 套利操作框架（风险套利的四问）

评估任何套利机会时回答：
1. 承诺事件发生的可能性有多大？
2. 资金锁定时间有多长？
3. 是否有更好结局（竞购等）？
4. 如果事件失败，损失多大？

## 七、并购标的筛选清单

巴菲特标准（1986年确立，1988年提高门槛）：

| # | 标准 | 说明 |
|---|------|------|
| 1 | 规模：税后净利润≥1000万美元 | 对大资金池有意义 |
| 2 | 持续盈利能力 | 历史记录，拒绝预测和"转机"故事 |
| 3 | 高ROE + 低负债 | 结构性优势，非杠杆驱动 |
| 4 | 管理层到位 | 无法空降管理 |
| 5 | 业务简单 | 能理解业务模式，拒绝高科技黑箱 |
| 6 | 明确报价 | 不谈没有价格的交易 |

**理想收购结构**（Blumkin-Heldman模式）：
- 创始人/家族希望变现部分财富
- 但愿意继续拥有并经营公司
- 多代家族参与，管理连续性有保障
- 出售给"永不转售"的买方

**拒绝清单**：新创业务、转机故事、拍卖式竞价、"相互了解就会有结果"的模糊安排。

## 八、会计警示：识别数字背后的真相

### 8.1 GAAP的三大失真场景

1. **购价调整失真**：收购后资产写高 → 折旧/摊销增加 → GAAP利润下降，但真实经济不变
2. **储备金操纵**（保险）：长尾业务的储备金估计高度主观，历史上大量公司故意低估
3. **"现金流"滥用**：(a)+(b) 而不减去(c)，严重高估实际可分配利润

### 8.2 资产负债表信号

- 好公司特征：资产轻（不需要大量固定资产），但"经济商誉"（品牌、特许经营权）极高
- 警惕：账面净值高但ROE低的公司（资产重，回报差）
- 好公司的商誉是**不在报表上**的（卓越管理和市场地位创造的价值）

### 8.3 核心三问（任何财报分析的锚点）

1. 这家公司大约值多少？
2. 它能否履行未来义务？
3. 管理层在给定条件下做得如何？

## 九、分析输出结构（建议格式）

完整的公司分析报告应包含：

```
1. 业务概述与护城河类型（商品型/特许经营型/混合）
2. 所有者收益计算（区别于GAAP利润）
3. 历史ROE趋势（≥5年，区分有无杠杆）
4. 管理层评估（能力/资本配置/品格）
5. 行业竞争格局与周期位置
6. 内在价值估算区间（非精确数字）
7. 风险因素（主要是基本面风险，非市场波动）
8. 结论：与现价比较，安全边际判断
```

## 十、常见错误提示

在分析时主动避免：

- ❌ 以市盈率替代内在价值判断
- ❌ 将"现金流"（未扣资本支出）视为真实盈利
- ❌ 用预测数字（特别是管理层提供的）代替历史记录
- ❌ 将短期市场表现与企业经营成果混淆
- ❌ 低估资本配置在长期回报中的作用
- ❌ 忽视保险公司储备金的主观性风险
- ❌ 把"账面价值增长"等同于"内在价值增长"
