# 巴菲特公司分析 2004-2005

## 核心姿态

把公司看成一组可长期复利的所有权资产，而不是一串会计利润或股价波动。最终计分牌是每股内在价值相对于低成本指数和其他机会的长期增长；账面价值、报表利润、实现资本利得和年度股价只是辅助线索。

估值要先拆开，再合并。对控股公司，至少分为每股投资资产、非保险经营收益、保险浮存金、债务和金融风险、总部资本配置能力。合并报表常把经济特征不同的业务搅在一起，直接看总数容易误判。

公司每天都在让护城河变宽或变窄。取悦客户、降低不必要成本、改进产品和服务，会累积成巨大价值；冷淡客户、容忍臃肿、为短期利润牺牲品牌和服务，会留下很难治愈的伤。

需要追溯方法来源时，读取 `references/source-notes.md`。

## 工作流

1. 校准计分牌
   - 先估每股内在价值，而不是先看市盈率、账面价值或一年利润。
   - 与股东可自己买到的低成本指数基金比较。若长期不能增加相对指数的每股内在价值，管理层没有创造增量价值。
   - 判断账面价值是否仍是内在价值的保守代理。若资产组合、会计规则或业务结构变化，账面价值的解释力会下降。
   - 对增长率保持怀疑。检查起点和终点是否异常；低基数、高景气终点、一次性收益都会制造漂亮但无意义的复合增长。
   - 承认规模拖累。资本越大，可显著影响整体结果的机会越少。

2. 分部还原经济实质
   - 将投资资产、现金、保险浮存金、非保险业务、金融产品、债务和总部费用分开分析。
   - 对每个分部只保留估内在价值有用的关键数字：资本占用、正常化税前收益、增量回报、债务结构、可持续竞争优势。
   - 判断控股公司是否带来增量：资本配置是否更好，子公司是否因信誉、长期资金、自治文化或交叉资源而更强。
   - 对制造、服务和零售业务，同时看有形净资产回报和包含商誉后的投入资本回报。高收购溢价会显著降低真实回报。
   - 对公用事业或基础设施，接受“巨额资本、受监管、合理回报”的逻辑，但要求现金流稳定、地域多元、债务不反噬母公司。

3. 判断业务质量和护城河
   - 优先选择简单、可理解、变量少的业务。若成功需要十个变量同时正确，即使每个变量胜率很高，整体胜率也会迅速下降。
   - 寻找低成本、品牌、服务、安全、分销、本地声誉、规模效率、监管结构、客户信任或特殊经理能力带来的持久优势。
   - 区分“规模大”和“经济性好”。收入巨大、利润率很薄、资本占用重的业务，必须证明周转效率和资本回报足够高。
   - 对资本密集业务，检查利用率。昂贵设备若利用不足，高收入也可能产生低回报。
   - 对周期性或行业低谷，不因短期利润差否定好业务，也不因高峰利润好而高估价值；使用正常化收益。
   - 把客户价值当作护城河证据。真正的低成本优势应转化为更低价格、更高留存、更强品牌和盈利增长的正循环。

4. 正常化收益和会计
   - 把经营收益、实现资本利得、未实现损益、外汇合同标记、并购会计收益、准备金调整和一次性费用分开。
   - 实现资本利得通常没有分析意义；卖出时点应服务于价格和机会成本，不应服务于报表利润。
   - 并购产生的会计收益若未改变经济所有权或现金税负，不应纳入经营能力。
   - 对“调整后利润”反向怀疑：若剔除坏运气，也要剔除好运气。
   - 股票期权是成本。若公司不费用化期权、用固定行权价奖励保留盈余带来的自然增值，要扣除这部分管理层转移。
   - 关注隐藏的资本配置损失。糟糕收购可能让股东价值永久消失，即使常规会计没有清楚显示。
   - 对贷款、证券化和金融子公司，区分前置确认利润和长期持有收益。更好看的报表不等于更好的经济结果。

5. 分析保险、再保险和浮存金
   - 保险只问三件事：浮存金有多少，成本是多少，数量和成本的长期前景如何。
   - 浮存金不是自动资产。只有长期成本低于替代资金成本，最好低于零，才创造价值。
   - 承保利润优先于保费规模。愿意在价格差时大幅收缩，是保险公司文化强度的核心测试。
   - 对商品化保险，优势通常来自两条路：像 NICO 一样宁可缩量也不低价承保，或像 GEICO 一样持续扩大低成本优势。
   - 对再保险，买的是长期承诺质量。对手方财务强度比名义费率更重要；弱再保险人的便宜承诺可能在巨灾后失效。
   - 对巨灾险，用最大行业损失、公司份额、资本承受力、相关性和“次年还能正常经营”测试，而不是只看历史平静期。
   - 不确定性上升时，用帕斯卡式下注思维：不知道气候、海温或频率是否改变，就要求明显更高价格并限制总暴露。
   - 长尾准备金要保守。保险坏消息常不对称，十个意外里可能九个偏坏；乐观准备金会虚增利润并误导奖励。

6. 审查债务、衍生品和金融风险
   - 默认回避母公司层面的重大债务。债务只在三类情况下可接受：短期高流动性证券策略、风险可理解且匹配融资的应收款组合、由稳定多元公用事业自身承担的债务。
   - 不为收购或普通经营加重大杠杆。对保单持有人、债权人和长期股东承诺“任何情况下支票能兑现”。
   - 压力测试时记住：再长的优秀数字序列乘以一个零仍等于零。只要一次极端事件能毁灭公司，历史高回报就不够好。
   - 对衍生品，把长期、多变量、难退出、mark-to-model 和补偿先行视为危险组合。
   - 检查交易员、CEO和奖金制度是否受益于先确认估计利润。现金多年后才验证的利润，最容易被想象力污染。
   - 对已有复杂金融业务，真正的盈利能力测试是在无增长、清仓或压力环境中还能否兑现账面价值。
   - 问退出成本。很多金融业务容易进入、极难退出；发现问题时要立刻行动，拖延会让负债迷宫变深。
   - 评估危机相关性。衍生品或再保险问题常在市场最差、机会最多时同时占用资本，机会成本巨大。

7. 评估收购和资本配置
   - 整家公司收购必须同时满足：业务长期经济性好，经理能干且诚实，价格能带来合理回报。
   - 默认买入后长期持有。不要依赖“退出策略”；真正重要的是进入价格和长期经济性。
   - 使用股票收购等同于出售现有业务的一部分。除非交出去的每股价值明显低于得到的价值，否则稀释旧股东。
   - 对每项收购只问根本标尺：得到的业务价值是否大于交出的现金、股票、债务和机会成本。
   - 快速、确定、现金式交易是优势，但不能替代价格纪律。
   - 优秀卖方和企业家会重视自治、声誉和永久归宿；收购后保留经理热情和地方品牌，往往比总部干预更有价值。
   - 资本闲置痛苦但合格。为了“做点什么”而降低标准，是资本配置错误。
   - Bolt-on 收购要增强原有优势，如纵向整合、区域密度、服务能力或成本结构，而不是只增加规模。

8. 分析普通股投资
   - 把股票当作企业的部分所有权，不按图形、传言或短期盈利预测买卖。
   - 分开看业务表现和市场表现。股价可能多年偏离业务增长；泡沫中价格先行，泡沫后业务可能追上。
   - 好公司不等于好价格。强大、盈利高但不便宜的一组股票，未来更可能跟随每股盈利温和增长，而不是创造奇迹。
   - 低成本、低换手、少折腾本身就是投资优势。总体投资者最终只能赚到企业总体盈利，扣掉交易、顾问、基金和激励费用。
   - 活动越多、帮手越多、费用越高，所有者整体回报越低。兴奋和费用是投资者敌人。
   - 不要用宏观观点替代价格价值计算。若需要外币暴露，优先考虑能赚真实利润的海外或多币种企业，而不是长期负 carry 的纯货币头寸。

9. 评估管理层、董事会和文化
   - 好经理像拥有者一样经营：把业务当作家庭未来一百年唯一资产，照顾业务需要后把多余现金交给最会配置的人。
   - 总部的价值在于配置资本、选择经理、维护文化和提供长期资金，不在于干预一线。
   - CEO质量极其重要。真正杰出的CEO很稀缺，也可能值得高薪；平庸CEO拿到不随表现约束的高薪，是股东转移。
   - 薪酬要按真实增量业绩设计。固定行权价期权会让CEO因保留盈余和回购自然变富，即使业务没有改善。
   - 合理期权至少应提高行权价以反映留存收益，设置长期持有要求，并防止经理迅速套现。
   - 董事独立性看真实经济动机，不看形式标签。董事应持有大量自己买入的股票，董事费不应成为重要收入来源。
   - 大股东和董事应盯住三件事：CEO是否正确，薪酬是否越界，收购是否增加每股价值。
   - 董事会必须定期无CEO会议、建立有效举报渠道、准备继任计划，并在CEO能力衰退时有勇气行动。
   - 文化检验看危机、错误和短期压力。能承认错误、迅速纠正、保护声誉和客户价值的文化，才值得长期托付资本。

## 输出格式

使用中文，写成“所有者备忘录”，结论先行：

1. 一句话结论：买入、持有、观察或回避，以及最关键理由。
2. 计分牌：每股内在价值、账面价值适用性、相对指数、机会成本、规模拖累。
3. 分部估值：投资资产、经营收益、保险浮存金、金融产品、债务和总部价值。
4. 业务质量：能力圈、护城河来源、客户价值、成本结构、资本强度、周期性和增量回报。
5. 正常化收益：一次性项目、资本利得、外汇/衍生品标记、准备金、期权、证券化和真实资本开支。
6. 保险与金融专项：浮存金成本、准备金、巨灾聚合、对手方、贷款质量、衍生品退出成本和流动性风险。
7. 资本配置：现金、回购、分红、债务、收购、股票发行、bolt-on、等待纪律。
8. 管理层与治理：CEO质量、薪酬、董事真实独立性、继任、举报机制、文化。
9. 估值与行动：当前价格隐含假设、安全边际、反证清单、需核实数据和等待条件。

## 判断准则

- 内在价值是区间估计，不是精确数字。未来越不确定，估值区间越宽，所需安全边际越大。
- 合并报表不是分析终点。业务经济特征不同，就必须拆开。
- 护城河每天变化。短期利润若伤害客户、成本位置、品牌或服务，是负价值利润。
- 简单变量胜过复杂模型。成功链条只要一个关键环节断裂，整体就失败。
- 浮存金先看成本，再看规模。高成本浮存金是杠杆化负担。
- 承保纪律体现在愿意少做坏生意，而不是在顺风年份报告漂亮利润。
- 再保险承诺质量比价格重要；弱对手方的低价保护常在最需要时消失。
- 衍生品的危险不在名称，而在期限、变量、估值主观性、奖金激励、流动性和危机相关性。
- 债务应能在极端情境下存活；为了多一点收益牺牲生存能力，是错误交易。
- 收购用股票不是免费货币，而是出售旧股东现有资产。
- 费用、换手和“帮手”会吞掉投资者总体回报；长期投资中少动常是主动选择。
- 董事的心跟着他的真实财富走。形式独立不如大额自有持股、低依赖董事费和敢挑战CEO。
- 当问题已经存在时，行动时间是现在。拖延通常让人员问题、金融风险和文化损害变得更贵。
